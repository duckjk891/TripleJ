## 2. 무료 이용자 1인당 월 비용

### ⚠️ 설계 전제와 코드 실태가 다름 (오픈전 리스트 B 등재됨)

- 차감은 **커버 −2, 캐릭터시트 −2 뿐** — **곡 생성·MV 생성은 포인트 차감 없음** → 현재 무료 이용자 생성량을 제한하는 장치가 없음.
- 적립 +1: 재생/발행/생성완료 (user×행위×곡×KST일 멱등 = 곡·행위당 하루 1회).
- AdMob 리워드: SSV 서명 검증까지 실연동, `skip_wait_count` 적립은 되는데 **소비하는 백엔드 코드 미발견**.
- → 곡·MV 차감(또는 레이트리밋) + AdMob 적립 소비 로직이 오픈 전 필수.

## 4. MAU 시나리오별 월 총 운영비

창작 활성 가정: MAU 의 10%가 월 곡 5회, 0.5%가 MV 1편, 발행 곡의 80%에 커버 → **1인당 API 변동비 평균 ≈ $0.23 (약 340원)**

|---|---|---|---|
| 5,000 | ≈$1,150 (170만원) | ≈$290 (43만원) | **≈ 월 210만원** |

**구조적 결론**
- 비용의 약 8할이 API 변동비이고, 그중 지배 항목은 **MV** (1편 ≈ 곡 생성 300회분).
- 곡 생성 자체는 매우 저렴 (회당 100원대).
- MV 이용률 가정(0.5%)이 1%p 오르면 총비용이 수백만 원 단위로 증가 → **MV 포인트 차감/유료화가 손익의 핵심 레버**.

## 부록 C. 코드 실사 요지 (호출 명세)

**곡 1개 발행 풀 코스**: 가사 LLM 1회 → Suno generate 1회(2곡 수신) → 타임스탬프 2회 → 커버 이미지 1회 → 키워드 1회 + 임베딩 1회. 포인트: 커버 −2, 생성완료 +1, 발행 +1.

**MV 1편 풀 코스** (씬 N, 자산 C+L=2~5, 립싱크씬 S): LLM 3~8회(브레인스톰/시나리오/씬프롬프트/커버분석) + 이미지 N+2~5회 + 비디오프롬프트(gemini-2.5-pro) N회 + 번역(claude-opus-4-7) N회 + 영상 N회(씬당 재시도 ≤3) + 립싱크 S회 + 로컬 ffmpeg 병합(무과금). MV 포인트 차감 없음(현재).
