# AIDOL — 서비스 공개 로드맵

> **AIDOL** — "아이돌"로 읽히는 AI 음악 창작 플랫폼.
> 가수 *아이돌(idol)* 을 누구나 *AI* 로 만들어 차트에 올린다는 정체성을 담았다.
>
> 본 문서 작성일: **2026-06-19** · 목표: **6월말 잔여 기능 구현 → 7/1 AWS 이전 → 7월 말 안정화·테스트 완료 + 구글 심사 통과(플레이스토어 등록) → 8/1 앱 다운로드 가능 + 웹(PC) 동시 공개**
>
> 공개 채널: **8/1부터 안드로이드 앱(구글플레이 다운로드)과 웹(PC) 버전을 함께 오픈**한다. 이를 위해 **구글 심사는 7월 말까지 완료**해 8/1엔 이미 플레이스토어에 등록돼 있어야 한다. 앱 프론트는 앱팀이 별도 제작(우리 4000 웹 프론트 참고), 웹(PC)은 4000 프론트를 정비해 공개. 앱·웹 모두 **동일한 백엔드 API(9005)** 를 공유한다.
>
> **핵심 창작 기능(보이스클로닝·가사생성·음악생성·커버이미지·차트 업로드)은 이미 구현 완료·동작 중.**
> **음악 검색·카테고리 분류 기능, 가상화 캐릭터(만화/그림체) 기능은 6월말까지 구현 완료 예정.**
> **7월부터는 신규 개발 없이**, 전 기능을 베타 공개에 대비해 철저히 **테스트·버그 제거·안정화** 한다.

| **앱 빌드 + Play Console 제출** | 2026-07 중순 (~7/22 목표) | 안드로이드 앱 빌드·서명, 구글플레이 등록·심사 제출 (심사 버퍼 확보 위해 조기 제출) |
| **구글 심사 통과 + 플레이스토어 등록** | 2026-07-31 | **7월 내 심사 완료**, 8/1 다운로드 가능하도록 스토어 등록 완료 |
| **베타 준비 완료 (백엔드)** | 2026-07-31 | 전 기능 테스트·버그 제거·안정화 완료, 운영 환경 세팅 (Feature Freeze) |
| **📱 앱 다운로드 시작 + 🖥 웹(PC) 공개** | 2026-08-01 | 플레이스토어에서 앱 다운로드 시작 + 웹(PC) 버전 동시 공개 |

> **인프라 전략:** 현재 서버는 개인 PC에서 구동 중. **7/1 AWS로 이전**해, 안정화 테스트의 본 무대를 처음부터 프로덕션과 동일한 AWS 환경으로 잡는다.
> (IT 정석: *"프로덕션과 동일한 환경에서 테스트하라."* 환경 의존 버그는 결국 AWS에서 다시 잡아야 하므로, 일찍 옮겨 테스트를 한 번만 돌린다.)
> - **백엔드는 9005만 AWS 배포.** 9004는 앱팀 전용 로컬 미러로 남기고 배포하지 않는다.
> - **베타는 안드로이드 앱(구글플레이)** 으로 공개. **앱은 4000 웹을 거치지 않고 백엔드 API(9005)를 직접 호출**한다. 따라서 클라이언트가 앱이어도 **리버스 프록시·TLS·도메인은 백엔드 API 앞단에 반드시 필요**하다 (안드로이드는 평문 HTTP 차단·고정 도메인·HTTPS 필수).
> - **리버스 프록시(Nginx)·TLS(HTTPS)·도메인·프로세스 매니저(WAS 워커)** 등 프로덕션 구성을 갖춰 올린다.
> - **웹(PC) 프론트(4000)도 8월에 앱 베타와 함께 공개.** 7월 안정화와 병행해 PC 버전으로 정비한다(앱·웹 동일 백엔드 API 공유).

| ⑦ | **카테고리 분류** | 🔨 ~6/30 | 장르 등 카테고리별 탐색·필터 (장르 차트 기반 확장) | `charts`(genre), `tracks` |

> **검색 아키텍처:** 임베딩은 **외부 API 임베더**로 생성(GPU 불필요, 검색어가 짧아 호출 비용 극소), 벡터 저장·유사도 검색은 **기존 PostgreSQL에 pgvector 확장**으로 처리(별도 vectorDB·서버 없음). 기존 곡은 1회 **임베딩 백필** 후, 신규 업로드 시 증분 임베딩.
> *(6월 구현은 로컬 개발환경의 pgvector로 진행하고, 프로덕션 확장 설치·전체 곡 백필은 7월 AWS 이전 단계에서 수행한다.)*

| ⑧ | **가상화 캐릭터 시트** | 🔨 ~6/30 | 만화/일러스트 그림체 캐릭터 시트 생성 영역 추가 (실사 유튜버 vs 버튜버 컨셉) | `character`, `character_generator` |

> ①~⑤ 창작 플로우는 **구현·동작 완료** 상태. ⑥~⑧ 탐색·가상화 캐릭터 기능은 **6월말까지 구현 완료** 후 7월 테스트 대상에 합류한다.
> 로드맵의 초점은 전 기능(①~⑧)을 **베타 사용자가 버그 없이 쓸 수 있도록 검증·안정화**하는 데 있다.

### 2.2 제외 / 연구 영역 (Out of Scope — 후속 공개)
