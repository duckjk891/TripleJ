# 멜론 차트 알고리즘 분석

> 우리 플랫폼 음원차트 설계의 기준 자료
> 조사일: 2026-04-07

---

## 1. 핵심 철학

**"소수 팬의 조작이 아닌, 다수 대중의 진짜 인기를 반영한다"**

---

## 2. 음원 점수 공식

```
음원 점수 = 스트리밍 순청취자 × 40% + 다운로드 순이용자 × 60%
```

- 스트리밍보다 다운로드에 더 높은 비중
- 다운로드 1건 ≈ 스트리밍 100회와 동등한 효과 (커뮤니티 분석 기준)

---

## 3. TOP100 차트 점수 (매시간 업데이트)

### 주간 (08:00 ~ 24:00)

```
TOP100 점수 = 24시간 이용량 × 50% + 최근 1시간 이용량 × 50%
```

- "24시간 이용량": 현재 시점 기준 과거 24시간 동안의 순 청취자 수
- "1시간 이용량": 현재 시점 기준 최근 1시간 동안의 순 청취자 수
- 최근 1시간이 50%나 차지하므로, **지금 이 순간 핫한 곡이 빠르게 순위 상승 가능**

### 심야 (01:00 ~ 07:00)

```
TOP100 점수 = 24시간 이용량 × 100%
```

- 최근 1시간 이용량을 **완전히 무시**
- **이유**: 새벽에는 일반 대중이 거의 활동하지 않아서, 소수 팬덤만으로 1시간 이용량을 폭등시켜 차트를 조작할 수 있기 때문
- 01:00, 08:00 차트는 전환 시점이라 순위 등락을 표시하지 않음

### 시간대별 실제 가중치 (커뮤니티 역공학 분석)

공식적으로는 50:50이지만, 실제로는 1시간 이용량에 **시간대별 변동 배수**가 적용되는 것으로 분석됨:

| 시간 | 1시간 배수 | 의미 |
|------|-----------|------|
| 08:00 | ~12 | 아침 (이용자 적음 → 배수 높음) |
| 12:00 | ~10 | 점심 |
| 15:00 | ~9 | 오후 |
| **19:00** | **~8** | **피크 시간 (이용자 많음 → 배수 낮음)** |
| 21:00 | ~10 | 저녁 |
| **00:00** | **~18** | **자정 (이용자 적음 → 배수 높음)** |

→ 이용자가 적은 시간대일수록 1시간 이용량의 영향력이 커지는 구조

## 4. 순 청취자 카운트 규칙

### 기본 원칙: 1인 1회

| 차트 | 카운트 규칙 |
|------|-----------|
| TOP100 (시간별) | 같은 곡을 1시간 안에 몇 번을 들어도 **1회**로 카운트 |
| 일간 차트 | 같은 곡을 하루에 몇 번을 들어도 **1회**로 카운트 |
| 주간/월간 차트 | 해당 기간 내 **1회**로 카운트 |

→ 한 사람이 100번 들어도 1명으로만 집계. **"몇 명이 들었냐"**가 핵심

### 카운트 되는 경우 ✅

- 유료 구독자가 곡을 처음부터 끝까지 (또는 일정 시간 이상) 재생
- 볼륨이 켜진 상태에서 정상적으로 청취

### 카운트 안 되는 경우 ❌

| 항목 | 이유 |
|------|------|
| 무료 미리듣기 (1분) | 유료 구독자만 차트 반영 |
| 볼륨 0 (음소거) 재생 | 2023.10월부터 제외 (주간 약 1억 회가 필터링됨) |
| 중간에 스킵 | 실제 청취가 아니므로 제외 |
| 일시정지 후 재생 | 정상 청취로 인정하지 않음 |
| 셔플(랜덤) 재생 | 차트 카운트에서 제외된다는 보고 있음 |
| 동일 곡 반복 재생 | 해당 시간 윈도우 내 1회 초과분은 무시 |

---

## 5. 다운로드 카운트 규칙

| 항목 | 규칙 |
|------|------|
| 기본 카운트 | 1인당 **최초 1회만** 카운트 |
| 재다운로드 | ❌ 카운트 안 됨 (이미 받은 곡 다시 받기) |
| 선물 다운로드 | 구매 시점이 아닌, **수신자가 실제 다운로드하는 시점**에 카운트 |
| 캐시 다운로드 | ❌ 카운트 안 됨 (오프라인 스트리밍용 임시 저장) |
| 영구 다운로드 | ✅ MP3, FLAC 등 영구 소장용만 카운트 |

## 6. 차트 종류 및 업데이트 주기

| 차트 | 집계 기간 | 업데이트 시점 | 특징 |
|------|----------|-------------|------|
| **TOP 100** | 24시간 + 1시간 롤링 | 매시 정각 | 메인 차트 |
| **HOT 100** | 최근 1시간만 | 매시 정각 (02~06시 미제공) | 발매 30일/100일 이내 신곡 전용 |
| **일간** | 24시간 (정오 기준) | 오후 1시 | |
| **주간** | 월~일 (월요일 정오 기준) | 월요일 오후 2시 | |
| **월간** | 1일~말일 (1일 정오 기준) | 익월 1일 오후 3시 | |
| **연간** | 1월 1일 ~ 12월 31일 누적 | 1월 초 | |

### HOT 100 차트 특징
- 발매 30일 또는 100일 이내 곡만 진입 가능
- 24시간 이용량 없이 **1시간 이용량만** 사용
- 새벽 02:00~06:00에는 차트 미제공
- 07:00 차트에는 순위 등락 미표시

## 7. 신곡 / 구곡 처리

| 항목 | 내용 |
|------|------|
| 신곡 부스트 | **없음** - 동일 공식으로 공정 경쟁 |
| 구곡 감쇠 (decay) | **없음** - 장기 차트인 곡에 페널티 없음 |
| 발매 시간 제한 | 12:00~18:00 발매 곡만 즉시 차트 반영 |
| 기타 시간 발매 | 00:00~11:00 → 당일 오후 1시 반영 / 19:00~23:00 → 익일 오후 1시 반영 |

→ 신곡/구곡 차등 없이 순수하게 "지금 얼마나 많은 사람이 듣고 있는가"로 경쟁
→ 이로 인해 장기 인기곡이 쉽게 안 떨어지는 **"콘크리트 차트"** 현상 발생

## 8. 사재기 방지 시스템

### 구조적 방지 장치

```
1인 1회 카운트     → 반복 재생 무력화
유료 구독자 전용    → 대량 무료 계정 생성 방지
심야 실시간 차단    → 새벽 총공 무력화
음소거 재생 제외    → 틀어놓고 안 듣기 방지
스킵/일시정지 제외  → 넘기면서 횟수 채우기 방지
발매 시간 제한      → 자정 발매 직후 총공 방지
```

### 기술적 탐지

| 항목 | 내용 |
|------|------|
| AI/ML 패턴 감지 | 반복 재생, IP 집중, 매크로 프로그램 탐지 |
| IP/디바이스 핑거프린팅 | 같은 IP/기기에서 과도한 재생 시 필터링 |
| 비정상 계정 탐지 | 대량 가입, 봇 계정 패턴 분석 |
| 실명/휴대폰 인증 | 계정 생성 시 본인 인증 필수 (2015년~) |

### 관리 체계

## 11. 참고 사항

### 차트 점수 vs 총 재생 수

| 용도 | 카운트 방식 |
|------|-----------|
| **차트 순위** | 순 청취자 (1인 1회) |
| **음악 시상식 (MMA 등)** | 총 재생 수 (반복 포함) |
| **Circle 차트 (구 가온)** | 총 재생 수 (반복 포함) |
| **아티스트 누적 통계** | 총 재생 수 (반복 포함) |

→ 같은 플랫폼이라도 용도에 따라 카운트 방식이 다름

### 멜론 차트가 "공정하다"고 평가받는 이유

1. 유료/무료 사용자 간 가중치 차등 없음 (전원 유료)
2. 신곡/구곡 차등 없음 (동일 공식)
3. 순 청취자 기반으로 반복 재생 조작 원천 차단
4. 심야 실시간 반영 차단으로 팬덤 총공 방지
5. 음소거/스킵/일시정지 등 비정상 청취 필터링
