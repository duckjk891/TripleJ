# 시험 APK(v3.391 + v3.392 합본) — 대표님 갤럭시 확인 순서

설치: 아래 링크를 휴대폰에서 열어 APK 설치(기존 시험 APK 위에 덮어 설치). 설치 후 **설정 > 버전**이 `v1.3.3 (빌드번호)` 로 보이면 새 앱입니다.

## 1. 재생 (v3.392 재생 엔진)
1. 재생목록 듣다가 '다음'을 빠르게 3번 → 한 곡만 나오는지
2. 화면 끄고 2~3곡이 자동으로 넘어가는지
3. 차(블루투스/안드로이드 오토) 다음·이전·일시정지
4. 미니플레이어 X → 소리·알림이 사라지는지
5. 노래 듣다 '광고 보기' → 광고 중 멈춤, 끝나면 이어 재생(멈춰 둔 상태였으면 그대로)

## 2. 다운로드가 폴더에 바로 저장되는지 (v3.391)
1. 아무 곡 ⋯ → 다운로드 → **음원만(mp3)** → 「내 파일 > 음악 > MAIDOL 폴더에 저장했어요」
   - **폴더 고르는 창·공유 창이 뜨지 않아야** 정상
   - 내 파일 앱 > 음악(Music) > MAIDOL 에 `곡 제목.mp3` 가 있는지
2. 같은 곡 → 다운로드 → **SNS용(세로)** → 갤러리 > 앨범 > **MAIDOL** 에 `곡 제목 (세로).mp4`
3. 작업실 > 영상 만들기에서 만든 영상 → [기기에 저장] → 갤러리 MAIDOL 앨범
4. (가능하면) 와이파이 끄고 다운로드 → 「파일을 받지 못했어요」 안내가 뜨고 "저장 완료"가 뜨지 않는지

## 3. SNS 공유
- 곡 ⋯ → SNS 공유 → **릴스**(또는 YouTube 쇼츠·틱톡) → 영상 만들기 끝나면 **공유 창**이 뜸 → 인스타그램 선택 → 영상이 붙어 있는지
  (예전처럼 영상 없이 업로드 페이지만 열리면 안 됨)

## 4. 키보드가 입력칸을 가리지 않는지
- 작업실 > 작사 → 아래 '직접 입력' 칸 누르기 → 입력칸이 키보드 바로 위에 보이는지
- 작곡 직접 입력, 커버 만들기 대화 입력, 곡 공유 문구(공유하기 화면), 크루 만들기, 설정 > 비밀번호 변경 — 같은 확인

## 5. 알림 켜기 배너
- 알림함 상단 '앱이 꺼져 있어도 … 알림을 받아보세요' 배너 → X 로 닫기 → 다른 화면 갔다 오기·앱 껐다 켜기 → **다시 안 뜨면** 정상

## 6. 얼굴 인증 카메라
- 실사 아티스트 만들기 → 얼굴 인증 → [지금 촬영하기] → **MAIDOL 안에서 전면(셀카) 카메라**가 바로 뜨는지 → 촬영 → 인증 진행
  (생성 직전 ⭐ 확인 창에서 [취소] 하면 별은 안 씁니다)

## 7. 광고
- 디렉터 휴식 '광고 보고 줄이기' → **실제 광고**(테스트 광고 표시 없음)가 나오고, 보면 휴식이 줄어드는지

## 8. 카톡 링크로 앱 열기 — 확인 파일 반영 뒤 시험
- 지금 APK 에는 앱 쪽이 다 들어 있지만, 서버·도메인에 확인 파일(assetlinks)을 올려야 링크가 앱으로 열립니다(대표님 승인 + Play 앱 서명 키 SHA-256 필요 — `app_links/APP_LINKS_SETUP.md`).
- 반영 뒤: 설정 > 애플리케이션 > MAIDOL > 기본으로 열기 > 지원되는 링크에 api.maidol.ai.kr 이 "확인됨" → 카톡·크롬에서 곡 링크 → 앱으로 열림.

## 9. 바로 업데이트(OTA) — 승인 후 시험
- 대표님이 허락하시면 시험 앱 전용 채널(preview)로 작은 글자 수정 1건을 OTA 로 보내 봅니다.
  앱을 껐다 켜거나, 앱으로 돌아왔을 때 「새 기능이 준비됐어요 [지금 적용]」 → 적용 후 설정 > 버전이 `v1.3.3 (빌드번호·시각)` 으로 바뀌면 성공.

# 아이폰(TestFlight) 확인 순서 — 다음 iOS 빌드 때
(iOS 빌드·TestFlight 제출은 스토어 제출이라 대표님 승인 후 진행)
1. 설정 > 프로필 사진 / DM 사진 / 문제 신고 사진 → **사진 보관함(사진첩)** 이 열리는지('파일' 앱이 아니라), 아이폰 카메라로 찍은 사진(HEIC)이 거부되지 않고 올라가는지
2. 아티스트 만들기 사진, 앨범 커버 바꾸기, 커버 배경 사진, 곡 업로드 커버 — 같은 확인
3. 얼굴 인증 → 앱 안 전면 카메라
4. 영상 [기기에 저장] → 사진 앱 'MAIDOL' 앨범 / 음원 다운로드 → 공유 창에서 "파일에 저장"
5. 키보드: 작사·작곡·커버 대화·공유 문구 입력칸이 예전처럼 키보드 위에 보이는지(아이폰은 기존 간격 그대로 유지)
6. (확인 파일 반영 뒤) 메모·카톡의 곡 링크를 길게 눌러 'MAIDOL에서 열기'
7. OTA: production 채널 업데이트 후 앱 재실행 시 반영
