# 안드로이드 구글 로그인(시스템 계정창) — 구글 클라우드 콘솔 설정 안내 (v3.385, 2026-10-21)

안드로이드 앱이 "Google 로 계속하기"에서 시스템 계정창을 띄우려면, **웹 로그인에 쓰는 것과 같은 구글 클라우드 프로젝트**에
"Android" 종류 OAuth 클라이언트가 있어야 합니다. 앱·서버 코드에는 새 값을 넣을 필요가 없습니다(콘솔 등록만).
등록 전에는 계정창이 실패하고, 앱이 자동으로 기존 브라우저 방식으로 넘어갑니다.

## 클릭 순서

### A. EAS 빌드 키용 클라이언트(시험 APK)
1. https://console.cloud.google.com 접속(웹 구글 로그인을 만든 계정) → 상단 프로젝트 선택에서 번호 832756935102 프로젝트 선택
   - 확인 방법: 왼쪽 메뉴 "Google 인증 플랫폼" → "클라이언트" 목록에 `832756935102-p4hn…` 웹 클라이언트가 보이면 맞는 프로젝트
2. "Google 인증 플랫폼" → "클라이언트" → **+ 클라이언트 만들기**
3. 애플리케이션 유형 **Android**, 이름 `MAIDOL Android (EAS)`, 패키지 이름 `com.maidol.app`, SHA-1 ① 붙여넣기
4. **만들기** (나오는 클라이언트 ID 는 어디에도 넣지 않아도 됩니다)

### B. Play 앱 서명 키용 클라이언트(스토어 버전)
1. https://play.google.com/console → MAIDOL 앱 → 왼쪽 **테스트 및 출시 → 설정 → 앱 무결성** → **앱 서명** 탭
2. "앱 서명 키 인증서"의 **SHA-1 인증서 지문** 복사
   - 같은 화면 "업로드 키 인증서" SHA-1 이 위 ①과 같은지도 확인(같아야 정상)
3. 구글 클라우드 콘솔로 돌아가 A-2~4 반복: 이름 `MAIDOL Android (Play)`, 패키지 `com.maidol.app`, SHA-1 = 방금 복사한 값

반영까지 보통 몇 분, 길면 수십 분 걸릴 수 있습니다.

## 확인
- 시험 APK 에서 "Google 로 계속하기" → 화면 아래에서 **시스템 계정창**이 올라오면 성공
- 계정창 대신 예전 브라우저 화면이 뜨면 = 콘솔 미등록/미반영 → 자동 폴백 동작(로그인은 그대로 됨)
