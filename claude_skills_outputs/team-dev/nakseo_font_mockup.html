카메라로 바로 낙서하기

웹(app.maidol.ai.kr)은 휴대폰 브라우저에서 카메라가 바로 열리고, 컴퓨터에서는 파일 고르기로 열려요. 아이폰 사진은 JPEG 로 바꿔 올리고, 안드로이드에서 카메라 도중 앱이 꺼져도 돌아오면 찍은 사진을 되살려요. 찍은 사진은 나중에 '낙서·사진으로 노래 만들기'에서도 그대로 쓸 수 있게 남겨 둬요.

함께 바뀌는 것

  • 하단 탭·화면 제목 일기장 → 낙서장, 상단 [전체]·[내 낙서]·[공지], 버튼 '낙서하기'
  • 스타 안내 '낙서하기 +3⭐', 새 소식·알림("새 낙서를 남겼어요")·AI 상담 안내도 낙서로
  • 손글씨는 낙서 본문에만 (날짜·버튼·메뉴는 지금 글꼴 그대로라 읽기 쉬움)
  • 앱이 무거워지지 않게 자주 쓰는 한글 2,350자만 담아요. 드문 글자(예: 똠, 햏)는 기본 글꼴로 보입니다.
  • '이 낙서로 노래 만들기'는 새 노래 만들기 방식이 정해질 때까지 숨겨 둡니다.
