# 9006→9004 미러링 완료 후 점검 체크리스트 (2026-08-31 작성)

> 백엔드팀이 9006(개발) → 9004(실서버) 미러링 중. 완료 신호를 받으면 아래 순서로 점검한다.

## 1. 기존 기능 회귀 스모크 (미러링으로 계약이 바뀌었을 수 있는 곳 — 자동 실행)

미러링에는 v205~v215 백엔드 변경이 포함되므로, 이미 PASS했던 것도 아래는 재확인:

- [ ] openapi diff: 미러링 전(2026-08-31 실측본) 대비 경로/스키마 변경 목록 추출 → 프론트 영향 분류
- [ ] 커버 계열(v3.89 + B-5 커버 보관함 v215가 같은 영역): generate-cover 응답 cover_session_id, refine/revert 체인, 트랙 확정 시 커버 부착
- [ ] 생성·발매 계열(v208/v210이 upload 커버 저장을 손댐): 곡 생성→A/B variant→upload-from-generation(variant_index, use_voice_converted) 정상
- [ ] 플레이어: v211 MV-곡 부착·동영상 탭 3순위 폴백이 들어옴 — 기존 재생·관련곡 이어듣기·비트뷰 회귀 확인, MV 있는 곡 재생 시 동작
- [ ] 마이뮤직: v209 "내 음악 탭 재편(작사실·작곡실·MV촬영실)"이 서버 응답에 영향 주는지 — 앱 마이뮤직(작곡/앨범/작사 탭) 정상
- [ ] 피로도·앨범·소명·DM·피드·consents·프로필 이미지·회원탈퇴·검색클릭·원격로깅: v3.99 [api] 스모크 재실행(스크립트 재사용 가능)
- [ ] 보이스 클로닝: 문구 도착 재확인(미러링이 voice_clone 서비스 코드를 바꿨을 수 있음)
- [ ] 곡 출처 기록(B-4 v214): 곡 생성 시 서버가 기록하는 출처(아티스트·목소리·가사)가 앱 전송 필드와 맞는지, "3곳 표시"가 앱 어디에 대응되는지 확인

## 2. 신규 착수 가능해지는 개발 (미러링 완료 = 착수 신호)

- [ ] **B-1 연동: 아티스트 N명 체제 전환** — /character/list·/character/{id} 실스키마로 MyArtists 개편(목록=서버, 슬롯당 1명, 개별 삭제, ⭐15 슬롯 정식화, gender 서버 필드)
- [ ] **B-3 연동: 아티스트↔목소리 매핑** — 프론트 voiceStore(로컬)를 서버 매핑으로 승격

- [ ] 신규 기능(v3.100 직접 업로드, v3.101 보호자 동의)의 9004 실서버 테스트
