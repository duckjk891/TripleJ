## ❌ 남은 것 (우선순위순)

### 1. [외부 블로커] 애플 개발자 법인 계정 — 심사 대기
- 2026-09-17 접수(케이스 K52Q5KXB89) 후 대기 중. **승인 전에는 iOS 사이닝·빌드·TestFlight 자체가 불가.**
- 액션: 애플 회신 대기(통상 2~4주, D+12일째). 승인 즉시 EAS iOS 크레덴셜 생성 → 빌드 가능.

### 2. [심사 블로커] Sign in with Apple 미구현
- 현재 소셜 로그인 = 구글·카카오. **제3자 소셜 로그인을 제공하는 앱은 애플 로그인 의무(가이드라인 4.8)** — 미구현 시 리젝 확정.
- 작업: 서버 OAuth(애플 id_token 검증 + 기존 소셜 가입 파이프 재사용) + 앱 버튼(expo-apple-authentication). 예상 규모: 서버 1라우트 + 앱 로그인 패널 1버튼 (기존 구글/카카오 파이프와 동형 — 1~2일).
- 의존: 애플 개발자 계정 승인(키 발급 필요) → **1번 해소 후에만 착수 가능.**

### 3. [기능 갭] AdMob iOS 보상형 광고 단위 미설정
- `resolveAdUnitId()`가 `ADMOB_REWARDED_AD_UNIT_ANDROID`만 참조 — iOS에선 테스트 광고 폴백(수익 0)·환경변수도 ANDROID만 존재.
- 작업: AdMob 콘솔에서 iOS 보상형 단위 발급 → `EXPO_PUBLIC_ADMOB_REWARDED_IOS` 추가 + Platform 분기 1곳. (30분)

### 4. [심사 리스크] `NSAllowsArbitraryLoads: true`
- ATS 전면 해제 상태 — 심사에서 사유 소명 요구 가능. api/app 도메인 모두 HTTPS(TLS1.2+)라 불필요.
- 작업: 제거(또는 특정 도메인 예외로 축소) 후 회귀 확인. (30분 + 실기기 확인)

### 5. [문구] 마이크 권한 설명 영문 기본값
- expo-audio 플러그인 `microphonePermission` 미지정 → "Allow $(PRODUCT_NAME) to access your microphone" 영문 노출(보이스 클론 녹음 시).
- 작업: 플러그인 옵션에 한국어 문구 1줄. (5분)

### 6. [검증 갭] iOS 런타임 검증 0회
- 개발 환경에 iOS 시뮬레이터 부재 — 계정 승인 후 TestFlight 실기기 검증 필수 목록:
  백그라운드 재생/잠금화면 · 보이스 녹음(마이크) · 영상 재생(Range) · 공유 시트 저장 · 소셜 로그인 리다이렉트 · AdMob 노출.

### 7. [선택] 차단 목록 클라 UI
- 서버 dm_blocks 존재·클라 필터는 서버 위임(코드 주석 기재) — 심사 통과에 필수는 아니나 UGC 정책 보강 여지.
