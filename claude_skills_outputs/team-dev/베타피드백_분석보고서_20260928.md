### A-10. [3] 아이폰에서 답변 수정 팝업이 사라지고 전 단계로 — P1 (원인 확정)

- 수정안: 백드롭을 별도 레이어로 분리(AppDialogHost 패턴). 사용처 3곳(작곡·작사·커버) 일괄 해결.

### A-11. [19] 옷 구경 후 ← 누르면 초기 화면 — P1 (원인 확정)
- 원인: 꾸미기 화면의 ← 버튼이 커버 경유가 아니면 무조건 **맵(초기 화면)으로 popTo**(`ArtistCodyScreen.tsx:774-797`). 진입도 replace라 돌아갈 스택 자체가 없음. 외부 쇼핑몰 새 탭 복귀는 보조 요인.
- 수정안: 진입을 navigate(+출발지 파라미터)로, ←는 goBack 가능하면 goBack.

### A-12. [22] 영상 저장·공유가 [보기]만 되는 원인 — P1 (원인 확정, C표 [22]와 연결)
- 원인: 저장·공유 모두 `window.open`(새 창) 방식(`VideoDirectorScreen.tsx:1043-1072`) → iOS Safari의 [보기]/[다운로드] 확인창이 뜨는 것. 공유 시트는 수 분 빌드 후 열어서 팝업 차단에 걸림. `navigator.share(files)`/`<a download>` 미사용, 파일 프록시가 구간 요청(Range) 미지원이라 iOS 재생 탐색도 불안정.
- 수정안: Blob 받아 기기 공유 시트(share files) 우선, 안 되면 a[download]. 서버 Range 지원 추가.
