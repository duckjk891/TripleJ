# 작사 프롬프트 체계 개편 (v3.110, 2026-08-31)

## 한 줄 요약
사용자에게는 "항목별 요약 카드"만 보여주고, 실제 작사 API에는 백엔드 계약(구조화 필드 + Suno 태그 구조 문장)에 딱 맞는 프롬프트를 숨겨서 보냅니다. 어색한 자연어 문단은 화면에서 사라졌습니다.

## 왜 바꿨나 (Before)
대화 12문답이 끝나면 답변을 한 문단으로 이어붙인 프롬프트를 사용자에게 그대로 보여줬습니다.

> **화면에 보이던 문장 (어색)**
> "한국어 100% 댄스 장르의 밝고 경쾌한 분위기 노래 가사를 작성해주세요. 곡 길이는 약 2분이고, 1인칭 — 나 시점으로 사랑에 대한 내용입니다. 구조는 절 — 후렴 (2절), 랩 파트 포함. 듀엣 곡으로 메인 보컬과 서브 보컬 파트를 구분하여 작성해주세요. 키워드는 바다입니다."

문제 3가지:
1. **어색함** — 선택지 라벨("한국어 100%", "1인칭 — 나")을 문장에 그대로 끼워 넣어 비문이 됨.
2. **중복 전송** — 장르·분위기·스타일·길이를 프롬프트에도 넣고 별도 필드로도 보내서, 백엔드가 같은 정보를 두 번 받음.
3. **백엔드 성능 미활용** — 백엔드는 duet 필드를 받으면 전용 듀엣 프롬프트([Female]/[Male] 라벨)를 쓰는데, AIDOL은 duet을 안 보내서 항상 솔로 프롬프트로 생성됨. 언어도 '영어 100%' 선택 시에도 'ko'가 아닌 라벨 문자열이 그대로 전송돼 항상 한국어 가사가 나옴.

## 어떻게 바뀌었나 (After)

### 1) 사용자 화면 = 쉬운 요약 카드 (프롬프트 원문 숨김)
확인 화면(LyricsPromptReview)이 3그룹 카드로 바뀌었습니다. 카드를 탭하면 그 항목만 팝업에서 수정.

- **이야기**: 주제 / 꼭 들어갈 말 / 시점 / 추가 요청
- **사운드**: 장르 / 분위기 / 스타일
- **구성**: 곡 구조 / 길이 / 랩 / 듀엣 / 언어

기존의 "② 작사 디렉터에 전달할 내용" 텍스트 상자(프롬프트 원문 편집)는 제거. 전문용어와 프롬프트 원문은 사용자에게 보이지 않습니다.

### 2) API 전달 = 구조화 (전송 직전에 자동 조립)
새 모듈 `utils/lyricsPrompt.ts` 의 `buildLyricsRequest()` 가 전송 직전에 조립합니다.

**전송 예시 (사용자에겐 안 보임):**
```
prompt:
  '사랑'을(를) 주제로 한 노래 가사를 써주세요.
  '바다' 소재를 가사에 자연스럽게 녹여주세요.
  1인칭 '나'의 시점으로 써주세요.
  곡 구조는 [Intro] - [Verse 1] - [Chorus] - [Verse 2] - [Chorus] - [Outro] 순서로 섹션 태그를 구성해주세요.
  랩 파트를 한 섹션 이상 포함해주세요 ([Verse: rap flow] 태그 활용).
  추가 요청: IU - 밤편지 느낌

genre: "댄스" / mood: "밝고 경쾌한" / style: "어쿠스틱"
duration_minutes: 2 / duet: true / language: "ko"
```

핵심 매핑:
- **곡 구조 선택지 → Suno 섹션 태그 시퀀스** ('절 — 후렴 — 브릿지' → `[Intro]-[Verse]-[Chorus]-[Bridge]-[Chorus]-[Outro]`) — 백엔드 시스템 프롬프트의 태그 규칙과 맞물림.
- **듀엣 선택 → duet: true** — 백엔드 듀엣 전용 프롬프트가 처음으로 활성화됨.
- **언어** — '영어 100%' → `language: "en"`, 혼합 선택은 비율 지시 문장으로 프롬프트에 반영.
- **길이** — 백엔드 분량 가이드(1·2·3분)에 맞춰 클램프, 4~5분 선택 시 "최대한 길게" 지시 추가. 30초도 이제 1분 가이드로 전달(기존엔 미전송 → 2분 기본값).
- 장르·분위기·스타일은 프롬프트 문장에서 제거하고 **필드로만** 전송(중복 해소).

### 3) 대화 질문 다듬기 (개수 동일, 12문)
- "듀엣 곡으로 작사하시겠어요?" → "혼자 부르는 곡인가요, 둘이 부르는 곡인가요?"
- "언어 비율은 어떻게 할까요?" → "가사 언어는 어떻게 할까요?"
- "가사 구조를 정해볼까요?" → "곡의 흐름(구조)은 어떻게 짜볼까요?" 등 5개 문구 순화.

### 4) 덤으로 잡은 버그
- 대화 중 "이전 답변 탭해서 재선택" 시 스텝 매핑이 한 칸씩 밀려(듀엣 스텝 추가 후 미반영) 엉뚱한 항목이 수정되던 버그 수정.
- 선택지가 두 화면(대화/확인)에서 서로 달랐던 것을 공용 상수로 통일.

## 백엔드 개선 제안 (수정 없이도 동작하지만, 고치면 더 좋아지는 것)
1. **duration_minutes 가이드 확장** — 현재 1·2·3분 가이드만 있고 4·5분은 2분 가이드로 폴백. 4~5분 가이드 추가 시 프론트 클램프 제거 가능.
2. **structure 필드 신설** — 지금은 구조를 prompt 문장으로 전달. `structure: "verse-chorus-bridge"` 같은 enum 필드를 받아 시스템 프롬프트의 STRUCTURAL RULES에 직접 주입하면 태그 준수율이 더 오를 것.
3. **language 혼합 비율** — `language` 가 ko/en 2값뿐. `english_ratio` (0~100) 같은 필드가 있으면 혼합 지시를 프롬프트 우회 없이 전달 가능.
4. **랩 여부 필드** — `has_rap: bool` 을 받아 시스템 프롬프트에서 처리하면 더 안정적.
