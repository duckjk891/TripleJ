목표: https://admin.maidol.ai.kr 에 들어가려면 먼저 **@lotusai.co.kr 메일로 온 6자리 코드**를 넣어야 하게 만듭니다.

- admin·api·business 세 주소 모두 Cloudflare 에서 **회색 구름**(서버로 바로 연결). 관리자 웹 정상.

## 1단계. 보안 연결 방식 확인 (1분)
> 10-19 대표 확인: 현재 **"전체(Full)"**. 무한 새로고침 문제는 없지만, Cloudflare가 서버 인증서를 검사하지 않습니다.
> → 존 전체는 그대로 두고, 아래 **구성 규칙으로 admin 주소에만 "전체(엄격)"**을 켜 주세요.

Cloudflare 대시보드 → **maidol.ai.kr** 선택 → 왼쪽 **SSL/TLS** → **개요(Overview)**
- **"전체(엄격)" / Full (strict)** 이면 → 그대로 2단계로.
- 다른 값(가변 Flexible·전체 Full 등)이면 **전체 설정은 바꾸지 마세요.** 대신 관리자 주소에만 적용:
  왼쪽 **규칙(Rules) → 구성 규칙(Configuration Rules) → 규칙 만들기**
  - 조건: 호스트 이름(Hostname) **같음** `admin.maidol.ai.kr`
  - 설정: **SSL → 전체(엄격) / Strict** → 저장
  - (이걸 안 하고 "가변"인 채로 켜면 관리자 웹이 무한 새로고침 됩니다.)

## 2단계. Zero Trust 팀 만들기 (처음 한 번, 3분)
대시보드 왼쪽 **Zero Trust** 클릭
- 팀 이름: `maidol` (로그인 화면 주소가 maidol.cloudflareaccess.com 이 됩니다. 이미 쓰이면 `maidol-admin`)
- 요금제: **Free(무료)** 선택. 카드 등록을 요구할 수 있는데 무료 요금제는 0원이라 청구되지 않습니다.

## 3단계. 로그인 방식 확인 (30초)
Zero Trust → **설정(Settings) → 인증(Authentication)** → 로그인 방법에 **One-time PIN** 이 있는지 확인 (기본으로 들어 있음. 없으면 "추가" → One-time PIN).

## 4단계. 관리자 주소 등록 (3분)
Zero Trust → **Access → 애플리케이션(Applications) → 애플리케이션 추가 → 자체 호스팅(Self-hosted)**
- 이름: `MAIDOL 관리자`
- 도메인(공개 호스트 이름): 하위 도메인 `admin`, 도메인 `maidol.ai.kr`, **경로는 비워 두기**(주소 전체를 막음)
- 세션 시간: **24시간** 추천 (하루 한 번 메일 코드. 너무 잦으면 1주일로)
- 로그인 방법: **One-time PIN** 만 체크

## 5단계. 누가 들어올 수 있는지 (정책, 2분)
같은 화면의 정책(Policies) 단계 → **정책 추가**
- 이름: `회사 메일`
- 동작(Action): **허용(Allow)**
- 포함(Include) → 선택기 **이메일 도메인 / Emails ending in** → `@lotusai.co.kr`
- 저장 → 애플리케이션 저장

## 6단계. 관리자 주소만 주황 구름으로 (30초) ← 꼭 4·5단계 다음에
maidol.ai.kr → **DNS → 레코드** → `admin` 줄 **편집** → 프록시 상태 **켬(주황 구름)** → 저장
- `api`·`business` 는 **회색 그대로** 두세요(앱·광고주 사이트).

## 7단계. 확인 (2분)
1. 크롬 **시크릿 창**으로 https://admin.maidol.ai.kr 열기 → Cloudflare 화면이 나옴
2. 회사 메일(예: jaguarlee@lotusai.co.kr) 입력 → 메일로 온 **6자리 코드** 입력
3. 평소 관리자 로그인 화면 → 로그인 → 대시보드 보이면 성공
4. (선택) gmail 주소를 넣으면 코드가 오지 않거나 거절되면 정상

이미 열려 있던 관리자 탭은 **새로고침** 한 번 해 주세요.

## 문제가 생기면 (바로 되돌리기)
DNS 의 `admin` 줄을 다시 **회색 구름**으로 → 1분 안에 지금과 똑같이 돌아갑니다.
