개인정보 내부관리계획 (초안)

주식회사 로터스에이아이 · 서비스: MAIDOL · 작성 2026-10-14 · 근거: 「개인정보 보호법」 제29조, 「개인정보의 안전성 확보조치 기준」 제4조
노란 표시 = 대표님이 채우거나 결정할 부분. 이 문서는 코드·운영 서버 기준 기술 초안이며 법률 자문이 아닙니다.

제1장 총칙

제1조 (목적)

이 계획은 회사가 MAIDOL 서비스를 운영하며 처리하는 개인정보가 분실·도난·유출·위조·변조·훼손되지 않도록 안전성 확보에 필요한 내부 관리 사항을 정한다.

제2조 (적용 범위)

MAIDOL 앱·웹(app.maidol.ai.kr), 서버(api.maidol.ai.kr, AWS 서울 리전), 관리자 웹(api.maidol.ai.kr/admin), 이를 운영하는 임직원·외주 인력과 개인정보 처리를 위탁받은 수탁자에 적용한다.

제3조 (용어)

개인정보 보호책임자(이하 "책임자"), 개인정보취급자(이하 "취급자"), 접속기록, 민감정보(얼굴 생체정보 등)는 개인정보 보호법령의 정의를 따른다.

제2장 조직과 책임

제4조 (개인정보 보호책임자 지정)

구분성명직위연락처
개인정보 보호책임자[대표이사 성명]대표이사(겸임)maidol_official@lotusai.co.kr
개인정보 보호담당자[성명 또는 "책임자 겸임"]

초기 단계에서는 대표이사가 책임자를 겸임하고, 필요하면 외부 자문을 둔다. 처리방침의 책임자 표기와 일치시킨다.

제5조 (책임자의 역할)

  • 내부관리계획 수립·시행·연 1회 이행 점검
  • 취급자 지정·권한 부여·회수 승인
  • 접속기록 월 1회 점검 확인(별첨 「접속기록 점검 기록부」)
  • 개인정보 유출 등 사고 대응 총괄, 정보주체 권리 행사(열람·정정·삭제·처리정지·자동화된 결정에 대한 설명·이의) 처리 감독
  • AI 사용 대장(별첨) 관리 — 새 AI 기능·외부 업체 도입 전 검토

제6조 (취급자)

취급자는 업무상 필요한 최소 인원으로 한정한다. 현재 관리자 권한 계정은 2개(role=admin), 공식 계정(customer) 8개이다.

계정권한담당 업무지정일
[관리자 계정 1]관리자[예: 신고·제재·상담]
[관리자 계정 2]관리자

제3장 기술적·관리적 보호조치

제7조 (접근 권한 관리)

  • 관리자 권한은 책임자 승인으로만 부여하고, 담당 변경·퇴직 시 지체 없이 회수한다. 부여·변경·회수 내역은 3년간 보관한다.
  • 관리자 권한은 현재 한 종류이다. 보완 필요: 열람 전용·제재 처리 등 역할 분리.
  • 얼굴 인증 면제는 관리자 기능(사유 필수)으로만 처리하며, 부여·해제가 감사 기록(admin_logs)에 남는다(v3.359).

제8조 (접근 통제)

  • 서버 접속은 키 기반 SSH로 한정하고, 데이터베이스는 외부에서 직접 접속할 수 없게 한다(같은 호스트 내부 통신).
  • 관리자 웹은 관리자 로그인과 세션 검증 후 이용한다.
  • 확인 필요: AWS 보안 그룹(허용 포트·접속 IP) 점검 결과를 기록한다(호스트 방화벽 ufw는 비활성, 보안 그룹으로 통제 중인지 확인).

제9조 (암호화)

대상방식
비밀번호일방향 암호화(bcrypt)
얼굴 생체정보대칭키 암호화(Fernet) 후 저장, 촬영 원본은 대조 후 즉시 파기
본인확인 식별값(DI)일방향 암호화(HMAC-SHA256)
통합된 계정 이메일일방향 암호화값만 보관(SHA-256)
전송 구간HTTPS(TLS)
비로그인 재생 기록 IP일방향 암호화값

암호화 키·API 키는 서버 환경 설정에만 두고 코드·문서·로그에 기록하지 않는다.

제10조 (접속기록 보관·점검)

  • 관리자의 개인정보 열람(사용자 상세·원본 사진·신고 증거·상담 대화·상담 케이스)과 변경 작업은 admin_logs 에 기록된다(v3.359).
  • 민감정보(얼굴)를 처리하므로 접속기록은 최소 2년 보관한다.
  • 책임자는 월 1회 접속기록을 점검하고 「접속기록 점검 기록부」에 남긴다(대량 열람, 업무 시간 외 열람, 사유 없는 원본 사진 열람, 권한 변동 확인).

제11조 (보관·파기)

항목보관 기간적용 방식
회원 정보(얼굴·원본 사진·음성·보낸 DM·푸시 구독·알림 포함)탈퇴 시 지체 없이 파기탈퇴 처리 자동(v3.359)
오류 기록90일자동 삭제
검색 기록·이용 분석·공유 방문180일자동 삭제
알림1년자동 삭제
비로그인 재생 기록32일자동 삭제
관리자 접속·열람 기록최소 2년보관
창작 기록(저작권 근거)곡이 남아 있는 동안, 탈퇴 후 비식별 형태추가 전용(수정·삭제 불가, v3.360)
로그인 회원 재생·다운로드 기록탈퇴 시 비식별 처리 후 차트·통계에만 이용탈퇴 처리 자동(v3.361)
서버 서비스 로그(배포 시 저장분·앱 로그·컨테이너 로그)90일매일 자동 정리(04:50 KST), 앱 로그 주 단위 압축(v3.363)

제12조 (백업·재해 대비)

데이터베이스(Postgres·MongoDB)는 매일 04:30(KST) 자동 백업한다. 서버 디스크에 7일(소유자만 읽기), AWS S3 비공개 저장소에 30일 보관한다(서버 밖 사본, 저장 시 암호화). 복구 시험은 분기 1회 하고 결과를 기록한다 — 2026-10-14 첫 복구 시험: 임시 DB 복원 결과 원본과 건수 일치(회원·플레이리스트·창작 기록, 곡·아티스트·재생 기록).
권장: 백업 전용 S3 버킷(버전 관리·자동 만료 설정)으로 옮기기 — AWS 콘솔 권한 필요.

제13조 (악성프로그램 방지·보안 업데이트)

서버 운영체제·컨테이너 이미지·주요 라이브러리 보안 업데이트를 정기적으로 적용하고, 적용 일자를 기록한다. [주기 결정 — 예: 월 1회]

제14조 (물리적 보호)

서버는 AWS 데이터센터에 있으며 물리적 보호는 AWS 보안 인증 범위에 따른다. 업무용 PC는 화면 잠금·디스크 암호화를 적용한다.

제4장 위탁·국외 이전 관리

제15조 (수탁자 관리)

수탁자·국외 이전 대상은 처리방침과 「AI 사용 대장」에 적고, 새 업체를 쓰기 전 책임자가 검토한다. 처리방침에 없는 업체로는 개인정보를 보내지 않는다(예: Sync Labs 사용 중지, v3.360). 사용자 음원은 외부 AI로 보내지 않는다.

제5장 정보주체 권리·사고 대응

제16조 (정보주체 권리 보장)

  • 열람·정정·삭제(탈퇴)·처리정지는 앱 설정과 고객센터(maidol_official@lotusai.co.kr)로 받아 10일 이내 처리한다.
  • 자동화된 결정(얼굴 대조로 실사 아티스트 생성 거부)에 대한 설명 요구·이의 제기는 담당자가 직접 검토하고, 필요 시 면제로 처리해 기록을 남긴다.
  • 만 14세 미만은 보호자(휴대폰 본인확인으로 성인 확인)의 동의를 받는다.

제17조 (유출 사고 대응)

  1. 인지 즉시 책임자에게 보고하고 접속 차단·비밀번호/키 교체 등 확대 방지 조치
  2. 유출 항목·규모·경위 파악
  3. 법령 기준에 해당하면 정보주체 통지(72시간 이내) 및 개인정보보호위원회·KISA 신고
  4. 재발 방지 대책 수립·기록

제6장 교육·점검

제18조 (교육)

취급자는 연 1회 이상 개인정보 보호 교육을 받는다(온라인 교육 가능). 교육 일자·내용·참석자를 기록한다.

제19조 (이행 점검)

책임자는 연 1회 이 계획의 이행 상태를 점검하고, 새 기능 출시·업체 변경 때 수시 점검한다(AI 거버넌스 점검과 함께).
