# 다듬기 테스트용 예시 본문

현재 등록된 자산:
- 캐릭터 시트(시트 이름 미입력 — 슬롯 키로 노출):
  - `@groom_casual`  (신랑 평상복)
  - `@groom_wedding` (신랑 웨딩 촬영복 — 턱시도)
  - `@bride_casual`  (신부 평상복)
  - `@bride_wedding` (신부 웨딩 촬영복 — 드레스)
- 장소: `@서울야경`

> 시트마다 "시트 이름" 칸에 `평상복 신랑`, `턱시도 신랑`, `원피스 신부`, `드레스 신부` 처럼 정해서 저장하면 멘션에서 그 이름으로 노출됩니다.

---

## 사용 방법
각 시점 textarea 에 아래 내용을 그대로 복사·붙여넣기 → `[✨ 다듬기]` 버튼 클릭 → Claude 4.7 Opus / GPT 최신 둘 다 시험해보세요. 모든 문장은 **제3자가 두 사람의 이야기를 설명하는 시점**(서술체)으로 작성되어 있고, **육하원칙**(언제/어디서/누가/무엇을/어떻게/왜)에 따라 사실 정보를 담고 있습니다. 일부러 표현이 거칠고 어순이 어색해서 다듬기 효과가 잘 보입니다. `@` 멘션은 보존돼야 합니다.

## 1. 첫 만남
```
두 사람은 재작년 12월 말, 같은 회사 송년회에서 처음 만났다. 송년회가 끝나고 다른 동료들은 다 가버린 회식 자리 끝자락에 @groom_casual 과 @bride_casual 둘만 남았다. 신랑은 후드티 위에 코트만 걸쳤고 신부도 가벼운 차림이었다. 두 사람은 어색하게 인사만 하다가 자연스럽게 한강 다리쪽으로 같이 걷게 됐고 그러다 @서울야경 이 보이는 벤치에 잠깐 앉았다. 그때 추워하는 신부에게 신랑이 말없이 코트를 벗어 건넸고 그 순간 두 사람 사이에 무언가가 시작됐다.
```

## 2. 첫 데이트
```
첫 만남이 있고 일주일 뒤 토요일 저녁, 신랑이 먼저 연락해서 다시 만나자고 했다. 두 사람은 같은 자리 @서울야경 이 보이는 벤치에서 다시 만났다. 신랑 @groom_casual 은 보온병에 따뜻한 율무차를 담아 왔다. 첫 만남 때 신부가 추위를 잘 탄다고 지나가듯 말한 걸 기억하고 있었기 때문이다. 신부 @bride_casual 은 그 작은 배려에 처음으로 마음이 흔들렸다. 두 사람은 야경을 보며 어릴 때 이야기, 가족 이야기, 직장 이야기를 두 시간 넘게 나눴고 시간이 어떻게 갔는지도 몰랐다.
```

## 3. 함께 쌓인 추억 (1)
```
첫 데이트 이후 주말 산책이 두 사람의 루틴이 됐다. 매주 토요일 또는 일요일 오전 @groom_casual 과 @bride_casual 은 편안한 차림으로 동네를 한 시간씩 걸었다. 편의점에서 커피를 한 잔씩 사서 손에 들고 별다른 대화 없이 걷는 시간이 두 사람에게 가장 편한 시간이었다. 비 오는 날에도 두 사람은 우산 하나를 같이 쓰고 걸었고 그렇게 사계절을 함께 보내며 서로의 일상이 됐다.
```

## 4. 함께 쌓인 추억 (2)
```
주말 산책이 익숙해진 어느 봄, 두 사람은 @서울야경 이 보이는 그 벤치를 다시 찾았다. 첫 만남과 첫 데이트가 있었던 그곳이었다. 두 사람은 그날따라 사진을 많이 찍었다. 신랑은 사진을 잘 못 찍었지만 @bride_casual 가 깔깔 웃는 모습을 여러 장 담았다. 그러다 둘이 셀카를 찍던 중 신랑이 자연스럽게 신부의 옆머리를 정리해줬다. 신부는 그 순간 두 사람의 거리가 어느새 이만큼 가까워졌다는 걸 깨달았다.
```

## 5. 결혼을 결심한 순간
```
지난 가을 어느 토요일 밤, 두 사람은 또 @서울야경 이 보이는 벤치를 찾았다. 신랑 @groom_casual 이 그날따라 평소와 다르게 진지한 표정이었다. 신랑은 가방에서 작은 케이스를 꺼냈고 신부 @bride_casual 의 심장은 멈추는 듯했다. 신랑은 길게 말하지 않고 "우리 같이 살자"라고만 했다. 그 짧은 한 마디에 신부는 눈물이 핑 돌았지만 떨리지는 않았다. 두 사람 안에서는 이미 오래전부터 답이 정해져 있었다.
```

## 6. 웨딩 준비 (드레스 / 촬영)
```
결혼을 결심한 다음 달부터 두 사람은 본격적인 웨딩 준비를 시작했다. 어느 토요일 오후, 두 사람은 함께 드레스샵을 찾았다. 신부 @bride_wedding 이 거울 앞에서 처음 드레스를 입어봤을 때 자기 모습이 어색하면서도 "이게 결혼하는 우리구나"라는 실감이 났다. 같은 날 옆방에서 신랑 @groom_wedding 도 턱시도를 입고 나왔다. 평소와 너무 다른 모습에 두 사람은 마주 보고 한참 웃었다. 다음 주말에는 야외 웨딩 촬영을 진행했고 카메라 앞에서 자꾸 웃음이 새어 나와 촬영작가가 진정시키느라 애를 먹었다.
```

## 7. 약속 — 서약 키워드 (3단계 입력)

위저드 Step 3 의 "서약 키워드" 칩 입력 칸에 아래 한 줄을 그대로 복사·붙여넣으면 콤마(,) 단위로 칩 4개가 한꺼번에 들어갑니다. 후렴(Chorus) 에 박히는 핵심 메시지로 쓰입니다.

※ 이 칸은 칩 입력(TagInput) 이라 `@` 멘션 기능이 없습니다. 평문 키워드로만 작성합니다.

```
함께 나이 들기, 약한 날 먼저 손잡기, 매년 같은 자리에서 야경 보기, 화나도 같은 방에서 자기

우리 둘이 여기까지 온 이야기 들어주셔서 감사합니다.
```

(선택) "자유 서약 한 줄" 칸 예시:
```
오늘처럼 서로의 눈을 가장 먼저 보는 사람이 되겠다.
```

- **Claude 4.7 Opus**: 한국어 자연체·정돈된 어순. 길이는 원본의 1.0~1.5배.
- **GPT 5.4 (최신)**: 약간 더 간결한 톤. 응답 5~8초.

각 시점마다 두 모델 번갈아 다듬어 보고 어느 쪽이 결혼식 영상 내레이션에 더 맞는지 비교해보세요. `@` 멘션 토큰은 두 모델 모두 보존되어야 정상이고, 만약 사라지면 모달 상단에 "⚠ 일부 멘션이 사라졌어요" 경고가 표시됩니다.
