## 1. 제품 정체성 (Product Identity)

### 1.1 브랜드
- **플랫폼명**: **PANN** (판)
- **어원**: 그리스·로마 신화의 신 **Pan (판)** — 목신, 자연의 신
- **상징 악기**: **팬플루트(Syrinx)** — 갈대로 만든 관악기
- **서사**: Pan이 태양신 Apollo와 음악 대결을 벌인 전설 → "음악의 도전자"
- **이름의 다의성**: PANN / 판(場·板·販) — 플랫폼/무대/거래의 의미 중첩

### 1.2 제품 컨셉
- **1인 기획사 시뮬레이션 + AI 음악 창작 플랫폼**
- 사용자 = 기획사 대표 ("대표님")
- AI 디렉터들 = 직원 (작사가 / 작곡가 / 이미지 디렉터 / 아티스트 디렉터 / MV 디렉터)
- 사용자가 성장 → 연습생 육성 → 레이블 규모 확장

### 1.3 타겟
- 주요: Z/알파 세대, 음악 창작 입문자
- 보조: 전문 크리에이터, 웨딩/조문 노래 의뢰인

### 1.4 브랜드 비주얼
- **톤**: 황혼(twilight), 전문 스튜디오, 신화적 서사
- **컬러**: 다크 보라 그라데이션 (Pan의 밤 → Apollo의 금빛으로 옮겨가는 황혼)
- **로고**: 팬플루트 실루엣 + PANN 타이포

## 3. 회의록 요약 (제품 브레인스토밍 5축)

### 3.1 UX 디렉션
- 작사 질문 ↔ 프롬프트 투명한 동기화
- 단계 명시 (현재/전체 단계 가시화)
- 프롬프트 사용량 증가 → 결과물 향상 (성장 곡선 체감)
- 기획사 이름 + 호칭 "대표님"으로 정체성 부여
- 전문 스튜디오 톤앤매너 (단순 생성기 아님)

### 3.2 에이전트(직원) 시스템
- AI 에이전트를 캐릭터로 영입/배치
- 작업실에 캐릭터 추가 → 작업 속도 증가 직관
- 확장: 에이전시 → 연습생 → 레이블

### 3.3 수익화 (PANN 경제)
- 웨딩 축가·조문 노래·영상 파일럿으로 초기 자금
- 상호 "도와주기" 구조
- 앱내 결제 + "판" 코인
- 단계별 광고 (작업 세분화와 결합)

### 3.4 소셜 레이어
- 인스타/카톡/유튜브 레이어 위 동작
- 짧은 영상 제작 중심
- 카톡 초대 바이럴

### 3.5 마케팅·커뮤니티
- 이달의 1위 인터뷰
- 경진대회 정기 개최
- 유저 챌린지 / 테스터 / 모임통장
- (주의) 초등학교 홍보 — 미성년자 규제 검토 필요

## 4. 세부 기능 아이디어 (7가지)

### 4.1 아티스트 디렉터 페이지 🟢
- 현재: "준비중"
- 백엔드: `/api/artists/` 이미 구현됨
- 작업: 아티스트 목록/상세/트랙 표시

### 4.2 착용 제품 링크 🟢
- 백엔드: `/api/business/ads/active?category=상의/하의/신발/장소` 이미 구현됨
- 위치: PlayerScreen 하단 + ArtistDetailScreen에 "💼 착용 아이템" 섹션
- 비로그인도 노출, 클릭 시 외부 링크 + 기록

### 4.3 비주얼 강화 (Lottie + Skia + Reanimated)
- 디렉터 캐릭터 모션 (Lottie)
- 방 분위기 효과 (Skia)
- 버튼/전환 인터랙션 (Reanimated)
- 차트 순위 애니메이션, 음파 시각화
- **PoC 권장**: 디렉터 1명만 변환하여 체감 확인

### 4.4 음성 대화
- 기술: OpenAI Realtime API or Whisper+GPT+TTS
- 비용: ~₩300~500/대화
- PoC: 작사 디렉터 1명만
- 고려: 마이크 권한, 배경 소음

### 4.5 작업실 UI 가이드 🟢
- 문제: 다음 할 일 안 보임, 방 역할 불명확
- 해결:
  - 진행 스텝퍼 (작사 → 작곡 → 커버 → 저장)
  - 다음 캐릭터 펄스/화살표 강조
  - 방별 라벨
  - 첫 방문 튜토리얼 오버레이

### 4.6 로딩 단계 세분화 + 단계별 광고 ⭐
- 현재: 대기번호 카운트다운만
- 제안: N개 세부 단계로 나누고 각 단계마다 캐릭터 모션 + 광고
- 효과:
  - 사용자 몰입 ↑ ("진짜 일하는 느낌")
  - 광고 자연스러운 분산 → 거부감 ↓
  - 수익 ↑
- 작사 예시: 분석 → 키워드 → 초안 → 라임 → 검토 (5단계)

### 4.7 배경음악 / 효과음
- BGM: 메인/작업실/결과 화면 별 분위기
- SFX: 버튼 탭, 메시지 알림, 완료 팡파레, 코인 획득
- 설정에서 BGM/SFX 토글 (기본 OFF 권장)
- 무료 소스: Pixabay, Mixkit, Freesound

### 4.8 작사 답변 ↔ 프롬프트 동기화 시각화 ✨ (기존 누락)
- 현재: LyricsPromptReviewScreen이 있지만 "내 답변이 어떻게 프롬프트에 반영됐는지" 연결 약함
- 제안: 각 답변을 프롬프트의 해당 부분에 하이라이트로 매핑
  - 예) "장르: 발라드" 선택 → 프롬프트 내 "장르: 발라드" 부분이 같은 색으로 하이라이트
- 효과: 투명성 ↑, "AI가 내 선택을 제대로 반영했구나" 신뢰감 ↑

### 4.9 성장 곡선 체감 UI ✨ (기존 누락)
- 현재: 곡을 많이 만들어도 사용자 체감 성장 없음
- 제안:
  - 기획사 레벨 표시 (곡 N개 생성 = 레벨업)
  - "이번 곡이 역대 최고!" 지표 (재생수/좋아요 비교)
  - MyMusic에 연대기 UI (월별/연도별 성장 그래프)
- 효과: "프롬프트 쓸수록 결과물이 나아진다" 느낌 체감

### 4.10 곡 플레이 시 프롬프트/설정값 보기 ✨ (기존 누락 + 버그)
- **현재 버그**: PlayerScreen에서 프롬프트 클릭해도 빈 화면, 아무것도 안 나옴
- 필요: 곡이 어떤 프롬프트/설정으로 만들어졌는지 투명하게 보여주기
- 표시 항목:
  - **작사 설정**: 장르 / 분위기 / 스타일 / 듀엣 / 내용 / 키워드 / 시점 / 언어 / 구조 / 랩 / 길이 / 추가요청
  - **작곡 설정**: 템포 / 보컬 / 보컬 스타일 / BPM / 키 / 레퍼런스 / 네거티브 태그
  - **가사 전문**
  - **AI 모델** (Suno / Wondera)
- 위치: PlayerScreen 하단 탭 또는 모달 ("📝 곡 정보")
- 백엔드: `GET /api/tracks/{id}` 응답에 이미 prompt/lyrics/genre/mood 등 있음 (확장 여부 확인 필요)
- 효과: 투명성 + 재현성 + 학습 (좋은 곡의 설정값을 사용자가 참고해서 다시 사용 가능)
