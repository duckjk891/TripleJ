# 디렉터 영입 시스템 설계 제안 (v38)

작성일: 2026-04-24
상태: **사용자 승인 대기중**

## 요약 (TL;DR)

> 모델별로 고유한 **디렉터 캐릭터**가 있고, 사용자는 **캐시**(플랫폼 내 화폐)로 이들을 **영입**합니다. 
> 영입한 디렉터만 작업실에 입주하며, 작곡/작사 시 직접 선택해 일을 시킬 수 있어요.
> 캐시는 **곡 생성 + 광고 시청** 두 경로로 획득합니다.

---

## 1. 왜 이 시스템인가

### 현재 문제
- 5종 작사 모델, 2종 작곡 모델이 그냥 "옵션"으로만 존재 → 감정 이입이나 성취감 없음
- 고가 모델(Opus, Suno) 사용 시 광고 6회로는 수지가 안 맞음 (`비용_재계산_v37.md` 참고)
- 사용자가 "내 스튜디오를 성장시킨다"는 감각이 약함

### 이 설계가 푸는 것
- **컬렉션 감각**: 디렉터마다 외형/성격/대사가 달라 "이번엔 이 분과 작업해볼까?" 선택의 재미
- **수익 구조**: 고가 디렉터는 영입 캐시가 비싸 → 사용자가 광고/결제로 캐시 축적 동기부여
- **Pay-wall이 아닌 Grind-wall**: 무료 사용자도 광고/활동으로 결국 도달 가능해 UX 낮아도 거부감 적음

## 3. 캐시 경제 (💎 Gem)

### 획득
| 액션 | 보상 |
|------|------|
| 곡 생성 (작사 완료) | **+30 💎** |
| 곡 생성 (작곡 완료) | **+50 💎** |
| 곡 생성 (커버 완료) | **+20 💎** |
| 일일 첫 접속 | **+10 💎** |
| 단계 스킵 광고 시청 | **+5 💎** (기존 스킵 효과 + 캐시 보너스) |
| 리워드 광고 (캐시 전용) | **+15 💎** (일일 10회 제한) |
| 차트 TOP 100 진입 (최초 1회) | **+500 💎** |
| 주간 챌린지 완료 | **+200 💎** |
| 신규 가입 | **+100 💎** |

**하루 최대 획득량**: 곡 3곡 생성 + 광고 20회 + 접속 보너스 ≈ 400 💎

### 소비
| 액션 | 비용 |
|------|------|
| 디렉터 영입 | 위 표 참고 (800~10,000 💎) |
| 대기 시간 즉시 완료 | **+100 💎** (모든 단계 스킵) |
| 디렉터 의상 변경 | **+200 💎** (후속) |
| 프리미엄 장르 팩 | **+500 💎** (후속) |

### 시나리오 예시
**일반 사용자** (주 5일, 일 2곡 생성):
- 주 수익: 2곡 × 7일 × (30+50+20) = **1,400 💎/주**
- 1개월 ≈ **5,600 💎**
- 한 달이면 소네트+포오 영입 가능

**고과금 사용자** (매일 접속, 광고 10회):
- 일 수익: 100(접속+광고) + 300(곡3) ≈ **400 💎/일**
- 2주 = 5,600 💎 → Opus 포함 전부 영입 + 의상 커스텀

**무과금 라이트**:
- 주 1~2곡, 광고 안 봄
- 월 ~600 💎 → 한 달에 소네트 영입 정도

## 4. 플로우 & UI

### 4-1. 영입 화면 (신규)
**진입 경로**: 하단 탭 "작업실" → 새 서브 메뉴 **"디렉터 라인업"** 또는 맵 별도 캐릭터 "에이전시" 배치

```
┌─ 디렉터 라인업 ───────────────────────┐
│  [보유 캐시 💎 1,250]                 │
│                                        │
│  작사 디렉터                           │
│  ┌────┐ ┌────┐ ┌────┐ ┌────┐ ┌────┐ │
│  │미니 │ │소네트│ │포오 │ │터보 │ │오퍼│ │
│  │영입✓│ │영입✓│ │1,200│ │2,000│ │5,000│ │
│  │     │ │     │ │💎   │ │💎   │ │💎   │ │
│  └────┘ └────┘ └────┘ └────┘ └────┘ │
│                                        │
│  작곡 디렉터                           │
│  [원더라 영입✓] [수노 3,500💎 영입하기]│
└────────────────────────────────────────┘
```

- 영입 카드 탭 → 상세 Modal (특기/샘플 곡/영입 비용/대사)
- 영입 버튼 → 캐시 확인 → 부족하면 "광고 보고 캐시 충전" CTA

### 4-2. 작업 할당 (수정)
기존 흐름: 작사 디렉터 클릭 → 바로 대화

새 흐름:
1. 작사실 디렉터 클릭
2. **보유 디렉터 목록 모달** 노출 (영입한 것만)
3. "어느 분께 맡기시겠어요?" 선택
4. 선택한 디렉터와 대화 시작
5. 대화 화면의 디렉터 초상화/대사가 선택된 분으로 교체

### 4-3. 맵 반영 (장기)
각 방 내부에 영입한 디렉터 캐릭터가 추가 배치 → 시각적 컬렉션 감각.
초기 단계에선 작사실엔 '미니'만, 영입 추가되면 소네트도 들어옴.

## 5. 기술 설계

### 5-1. 백엔드 스키마 (요청 사항)

#### 테이블 신설
```sql
-- 디렉터 카탈로그 (시드 데이터)
CREATE TABLE directors (
  id VARCHAR(32) PRIMARY KEY,          -- lyr_mini 등
  display_name VARCHAR(50) NOT NULL,   -- '미니'
  category VARCHAR(20) NOT NULL,       -- lyricist/composer/image/video
  model_key VARCHAR(50) NOT NULL,      -- 'lyrics_gpt4o_mini' 등 timerStore와 대응
  hire_cost INT NOT NULL DEFAULT 0,    -- 영입 캐시
  tier SMALLINT NOT NULL DEFAULT 1,    -- 1~5
  portrait_url TEXT,
  concept_text TEXT,                   -- 컨셉 설명
  sample_dialogues JSONB,              -- 인사말/결과 보고 멘트
  is_default BOOLEAN DEFAULT FALSE     -- 신규 가입 시 기본 지급 여부
);

-- 사용자 보유 디렉터
CREATE TABLE user_directors (
  user_id UUID REFERENCES users(id) ON DELETE CASCADE,
  director_id VARCHAR(32) REFERENCES directors(id),
  hired_at TIMESTAMP DEFAULT NOW(),
  PRIMARY KEY (user_id, director_id)
);

-- 사용자 캐시 원장
CREATE TABLE user_gems (
  user_id UUID PRIMARY KEY REFERENCES users(id) ON DELETE CASCADE,
  balance INT NOT NULL DEFAULT 100,
  updated_at TIMESTAMP DEFAULT NOW()
);

-- 캐시 거래 로그 (감사/디버깅)
CREATE TABLE gem_transactions (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  user_id UUID REFERENCES users(id) ON DELETE CASCADE,
  delta INT NOT NULL,                  -- +획득 / -소비
  reason VARCHAR(50) NOT NULL,         -- 'track_created','ad_reward','hire_director' 등
  ref_id VARCHAR(100),                 -- 트랙 id, director id 등
  created_at TIMESTAMP DEFAULT NOW()
);
```

#### API 엔드포인트
```
GET  /api/directors                      -- 전체 카탈로그 + 내 영입 상태
POST /api/directors/{id}/hire            -- 영입 (캐시 차감)
GET  /api/gems/balance                   -- 잔액
GET  /api/gems/transactions?limit=50     -- 최근 거래
POST /api/gems/earn/ad                   -- 광고 리워드 (검증 토큰 필요)
                                          -- 트랙 생성 보상은 서버 내부 훅에서 자동
```

### 5-2. 프론트 작업

**신규 파일**:
- `screens/DirectorLineupScreen.tsx` — 영입 화면
- `stores/gemsStore.ts` — 잔액/거래 캐시
- `stores/directorsStore.ts` — 영입한 디렉터 리스트 + 선택 상태

**수정 파일**:
- `MapScreen.tsx`: 작사/작곡 디렉터 클릭 → 영입한 디렉터 선택 모달
- `DialogueScreen.tsx`: 선택된 디렉터 프로필로 렌더
- `App.tsx`: DirectorLineup 라우트 추가
- `ChartScreen.tsx` 헤더 우측에 💎 잔액 뱃지
- `timerStore.ts`: startTask 시 `directorId` 파라미터 추가, 완료 시 캐시 +30/+50/+20 보상 hook

### 5-3. 로컬 백엔드 미비 시 MVP

백엔드 반영 전까지 프론트만으로 데모 가능하도록:
- `AsyncStorage`에 임시 캐시 잔액 저장 (zustand persist)
- 디렉터 카탈로그는 프론트 상수로 하드코딩
- 영입은 로컬 배열에만 추가
- 실제 모델 선택은 기존 `musicStore.selectedModel`, `timerStore` modelKey로 매핑

→ 나중에 백엔드 머지 시 API로 전환하면 됨.

## 7. 주의할 것

- **Pay-to-Win 회피**: 고가 디렉터가 꼭 더 좋은 결과를 내는 것처럼 보이지 않도록. "취향 차이"로 포지셔닝
- **신규 유저 장벽**: 초기 캐시 100 💎은 아무것도 못 사니 → 기본 디렉터(미니 + 원더라/수노 택1)를 충분히 제공
- **캐시 인플레이션**: 곡 생성당 보상이 너무 크면 고가 디렉터 가치 급락. 현재 설계는 일반 사용자 기준 월 1~2명 영입 페이스로 균형
- **광고 남용**: 일일 리워드 광고 10회 cap. 그 이상 봐도 캐시 지급 X
- **환불/소실**: 디렉터 삭제 기능은 제공 X (캐시 환불 민원 원천 차단)

## 8. 결정이 필요한 지점

다음 중 어느 방향으로 갈지 선택 부탁드립니다:

1. **Phase 1만 이번 세션에 MVP 구현?**
   - 예 → 바로 코드 작성 시작 (캐시 스토어 + 영입 화면 + 선택 모달)
   - 아니오 → 본 설계 문서만 남기고 백엔드 스펙 먼저 정리

2. **캐시 단가**:
   - 위 제안대로 (곡당 100 ≈ 평균 사용자 월 1명 영입)
   - 더 넉넉하게 (곡당 200 ≈ 월 2~3명)
   - 더 짠물 (곡당 50 ≈ 월 0.5명)

3. **무료 시작 디렉터**:
   - 미니 + 원더라/수노 택 1 (제안)
   - 미니만 (작곡은 모두 유료)
   - 미니 + 수노 (모두 제공)

4. **MV(영상 디렉터)**:
   - 10,000 💎 초고가 (희소 아이템)
   - 현재 계획 유지 (유료 플랜 잠금)
   - 무료 (단, 대기 매우 길게)

답 주시면 Phase 1 MVP 바로 착수하겠습니다.
