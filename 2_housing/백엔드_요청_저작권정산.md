# 백엔드 요청 — 음원 저작권 다운로드 결제 / 정산 시스템

작성일: 2026-04-28
요청 출처: 모바일 앱 v44 (PLAN.md)
정책 결정: 가격 ₩500 / 부가세 9% / PG 3% / 플랫폼 22% / **Creator 66%**

## 1. 비즈니스 개요

- 사용자가 만든 음원은 그 사용자(creator)의 **플랫폼 내부 가상 저작권**으로 자동 등록
- 다른 사용자가 그 곡을 **다운로드(mp3/wav)** 할 때 ₩500 결제 → 정산
- **스트리밍(듣기)은 무료** (인기도 EXP에만 기여)
- creator는 누적 매출이 ₩10,000 이상이면 통장 출금 가능 (수수료 ₩1,000)

## 2. DB 스키마 변경 (PostgreSQL)

### 2-1. `tracks` 테이블에 컬럼 추가
```sql
ALTER TABLE tracks ADD COLUMN download_price_krw INT NOT NULL DEFAULT 500;
ALTER TABLE tracks ADD COLUMN downloads_count INT NOT NULL DEFAULT 0;
ALTER TABLE tracks ADD COLUMN copyright_registered_at TIMESTAMPTZ DEFAULT NOW();
-- creator_id는 기존 user_id 컬럼 재사용 (변경 불필요)
```

### 2-2. `track_purchases` 신규
사용자가 다른 사용자의 곡을 구매한 기록.
```sql
CREATE TABLE track_purchases (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  buyer_id UUID NOT NULL REFERENCES users(id),
  track_id UUID NOT NULL REFERENCES tracks(id),
  creator_id UUID NOT NULL REFERENCES users(id),
  price_krw INT NOT NULL,
  payment_id UUID NOT NULL REFERENCES payments(id),
  license_type TEXT NOT NULL DEFAULT 'personal',  -- 'personal' | 'commercial' (v2+)
  download_url TEXT,                              -- 백엔드가 발급한 presigned URL
  download_url_expires_at TIMESTAMPTZ,
  created_at TIMESTAMPTZ DEFAULT NOW(),
  UNIQUE(buyer_id, track_id)                      -- 한 번 구매한 곡은 재구매 불필요
);
CREATE INDEX idx_purchases_creator ON track_purchases(creator_id);
CREATE INDEX idx_purchases_buyer ON track_purchases(buyer_id);
```

### 2-3. `payments` 신규
PG 결제 트랜잭션 원장.
```sql
CREATE TABLE payments (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  buyer_id UUID NOT NULL REFERENCES users(id),
  amount_krw INT NOT NULL,
  pg_provider TEXT NOT NULL,                  -- 'tosspayments' 등
  pg_payment_key TEXT,                        -- 토스 paymentKey
  pg_order_id TEXT NOT NULL UNIQUE,
  status TEXT NOT NULL DEFAULT 'pending',     -- pending | completed | failed | refunded
  failure_reason TEXT,
  meta JSONB,                                 -- 트랙 ID, 라이선스 등
  created_at TIMESTAMPTZ DEFAULT NOW(),
  completed_at TIMESTAMPTZ
);
```

### 2-4. `royalty_ledger` 신규
creator별 정산 이벤트 (매출 +, 출금 -).
```sql
CREATE TABLE royalty_ledger (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  user_id UUID NOT NULL REFERENCES users(id),
  delta_krw INT NOT NULL,                     -- 매출 +, 출금 -
  source TEXT NOT NULL,                       -- 'sale' | 'payout' | 'adjustment'
  ref_id UUID,                                -- track_purchases.id 또는 payouts.id
  created_at TIMESTAMPTZ DEFAULT NOW()
);
CREATE INDEX idx_ledger_user_created ON royalty_ledger(user_id, created_at DESC);
```

### 2-5. `payouts` 신규
creator의 출금 신청 기록.
```sql
CREATE TABLE payouts (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  user_id UUID NOT NULL REFERENCES users(id),
  amount_krw INT NOT NULL,
  fee_krw INT NOT NULL DEFAULT 1000,
  bank_name TEXT NOT NULL,
  account_number TEXT NOT NULL,                -- 암호화 저장 권장
  account_holder TEXT NOT NULL,
  status TEXT NOT NULL DEFAULT 'requested',    -- requested | processing | completed | failed
  failure_reason TEXT,
  requested_at TIMESTAMPTZ DEFAULT NOW(),
  completed_at TIMESTAMPTZ
);
```

## 3. API 엔드포인트

### 3-1. `POST /api/tracks/{track_id}/purchase`
**요청** (인증 필요):
```json
{ "license_type": "personal" }
```

**응답 (200)** — PG 결제 페이지로 redirect 유도:
```json
{
  "payment_id": "uuid",
  "pg_order_id": "ord_...",
  "amount_krw": 500,
  "tosspayments_client_key": "test_ck_...",
  "redirect_url": "https://api.tosspayments.com/...",  
  "success_callback": "tripleJ://payment/success",
  "fail_callback": "tripleJ://payment/fail"
}
```

**에러**:
- `400 already_purchased` (이미 구매한 곡)
- `400 own_track` (본인 곡은 무료 다운로드, 이 엔드포인트 호출 불필요)
- `404 track_not_found`

### 3-2. `POST /api/payments/webhook/tosspayments`
토스페이먼츠 결제 완료 콜백. 서명 검증 후 status='completed' 갱신 + ledger insert.
정산 분배:
- 부가세 9% → 별도 처리 (월말 부가세 신고용 적립)
- PG 수수료 3% → 토스 측 차감
- 플랫폼 22% → 플랫폼 매출
- creator 66% → `royalty_ledger.delta_krw = +amount * 0.66`

### 3-3. `GET /api/me/royalty/summary`
```json
{
  "total_earned_krw": 12340,        // 누적 매출
  "available_krw": 8340,             // 출금 가능 (이미 출금된 거 제외)
  "pending_payout_krw": 4000,        // 출금 진행 중
  "downloads_count": 36,
  "min_payout_krw": 10000,
  "payout_fee_krw": 1000
}
```

### 3-4. `GET /api/me/royalty/ledger?page=1&limit=20`
정산 내역 (매출/출금 시간순).

### 3-5. `POST /api/me/royalty/payout-request`
```json
{
  "amount_krw": 10000,
  "bank_name": "토스뱅크",
  "account_number": "encrypted",
  "account_holder": "홍길동"
}
```
- 검증: `amount >= min_payout (10000)`, `available_krw >= amount + payout_fee (1000)`
- ledger에 `-amount` 한 줄 + `payouts` 신규
- status='requested' → 운영자 처리 후 'completed'

### 3-6. `GET /api/tracks/{track_id}/download-url`
구매한 트랙의 다운로드 URL 발급. `track_purchases` 검사, 본인 트랙이면 무조건 통과.
응답: presigned MinIO URL (24h 만료).

## 4. PG 통합 (토스페이먼츠 권장)
- 한국 친화 + REST API 깔끔
- 클라이언트 키 / 시크릿 키 발급 → 환경변수
- 결제창은 클라이언트(앱)에서 토스 SDK 또는 redirect 방식
- 모바일은 React Native용 toss-payments-react-native (또는 WebView)

## 5. 라이선스 정책 (v1)
- **개인용** (`personal`): 본인 청취/소장 한정, 상업적 사용 금지
- 다운로드 시 약관 동의 체크박스 (UI에 명시)
- 상업용 라이선스는 v2+ (가격 다르게)

## 6. 사업자 / 법적 인프라 (운영팀 결정)
- 통신판매업 신고
- 부가세 신고 (월별/분기별)
- 사업소득 원천징수 3.3% (creator가 사업자 미등록 시)
- 환불 정책 (다운로드 직후엔 환불 불가 명시)
- 약관 / 개인정보처리방침 갱신
