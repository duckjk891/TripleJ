# 백엔드 요청: 보호자 관리 API

어린이 모드 기획서(`어린이모드_기획서.md`)의 E2·E5 항목입니다. 보호자가 보는 웹 페이지는 이미 만들어 `https://maidol.ai.kr/guardian/`에 올려 두었고, 이 문서의 API가 생기면 바로 동작합니다. 페이지 소스는 홈페이지 저장소 `maidol/www/guardian/index.html`입니다.

미리보기: `https://maidol.ai.kr/guardian/?demo=consent` (동의), `?demo=manage` (관리). 서버를 부르지 않고 흉내 낸 응답으로 화면만 보여줍니다.

## 1. 링크 형식 (알림 어댑터 수정)

보호자에게 보내는 링크를 아래 주소로 맞춰 주세요. 페이지는 두 파라미터로 화면을 나눕니다.

| 용도 | 주소 | 토큰 |
| --- | --- | --- |
| 가입 동의 | `https://maidol.ai.kr/guardian/?token={consent_token}` | 지금의 `guardian_consents.consent_token` (72시간 유효) |
| 동의 후 관리 | `https://maidol.ai.kr/guardian/?manage={manage_token}` | 새로 발급 (만료 없음) |

- `send_guardian_consent_notification`이 만드는 `consent_url`을 위 가입 동의 주소로 바꿉니다.
- 동의 링크는 동의가 끝나면 409, 만료되면 404가 되므로 관리에 다시 쓸 수 없습니다. 그래서 관리 토큰을 따로 둡니다.

## 2. 기존 동의 API 변경 (작게)

`POST /api/auth/guardian-consent/{token}/decide`에서 **동의(`agree: true`)이고 `consent_type`이 `signup`일 때**:

1. `manage_token = secrets.token_urlsafe(32)`를 만들어 저장합니다.
2. 관리 링크를 보호자 휴대폰으로 문자 발송합니다. 목(mock) 모드에서는 발송 대신 응답에 넣습니다.
3. 응답에 `manage_url`을 추가합니다 (목 모드에서만, `consent_url`과 같은 규칙).

```json
{ "status": "agreed", "message": "동의가 완료되었습니다. 아동 계정이 활성화되었습니다.", "manage_url": "https://maidol.ai.kr/guardian/?manage=..." }
```

페이지는 `manage_url`이 있으면 "보호자 관리로 이동" 버튼을, 없으면 "관리 링크는 문자로 보내드립니다" 안내를 보여줍니다.

## 3. 저장할 값

`guardian_consents`에 열을 추가하거나 별도 테이블을 둡니다. 자녀 계정 하나에 보호자 관리 레코드 하나입니다.

| 열 | 타입 | 기본값 | 설명 |
| --- | --- | --- | --- |
| `manage_token` | text, unique | — | 관리 링크 토큰 |
| `feed_post` | bool | `false` | 피드 글쓰기·피드 댓글·곡 댓글 허용 |
| `dm_friends` | bool | `false` | 서로 팔로우한 친구와 DM 허용 |
| `otp_exempt` | bool | `false` | 휴대폰 인증 생략. **심사용 테스트 계정에만** `true` |
| `revoked_at` | timestamptz | null | 동의 철회 시각 |

`feed_post`, `dm_friends`는 기획서 F1(DM)·F3(피드·댓글) 제한에서 읽고, `GET /auth/me`의 보호자 설정값(E1)으로도 내려줍니다.

## 4. 새 API

모두 `/api/guardian/manage/{manage_token}` 밑입니다. 로그인(JWT)이 아니라 **관리 토큰 + 휴대폰 인증 세션**으로 보호합니다. 세션은 `Authorization: Bearer {session_token}` 헤더로 옵니다. CORS는 지금 설정으로 `https://maidol.ai.kr`에서 `Authorization` 헤더가 허용되는 것을 확인했습니다.

### GET `/api/guardian/manage/{manage_token}`

| 경우 | 응답 |
| --- | --- |
| 정상 (세션 유효, 또는 `otp_exempt`) | `200` 아래 본문 |
| 세션 없음·만료 | `401 { "error": "verification_required", "phone_masked": "010-****-5678" }` |
| 토큰 없음 | `404 { "error": "보호자 관리 링크를 찾을 수 없습니다." }` |

```json
{
  "child_nickname": "냥냥이",
  "age": 10,
  "account_status": "active",
  "consented_at": "2026-09-22T12:00:00+09:00",
  "settings": { "feed_post": false, "dm_friends": false }
}
```

- `child_nickname`은 마스킹하지 않습니다. 인증을 통과한 보호자에게만 보여주기 때문입니다.
- `account_status`는 `active` 또는 `suspended`(동의 철회)입니다.

### POST `/api/guardian/manage/{manage_token}/otp`

보호자 휴대폰(`guardian_phone`)으로 6자리 인증번호를 문자 발송합니다.

- 인증번호 유효 시간 5분, 같은 토큰으로 1시간에 5번까지만 발송합니다.
- 응답 `200 { "phone_masked": "010-****-5678" }`, 한도 초과 `429 { "error": "..." }`

### POST `/api/guardian/manage/{manage_token}/otp/verify`

- 요청 `{ "code": "123456" }`
- 맞으면 `200 { "session_token": "...", "expires_in": 1800 }`. 세션은 30분 동안 쓰는 무작위 토큰이고, Redis에 관리 토큰과 묶어 저장합니다.
- 틀리면 `400 { "error": "인증번호가 맞지 않습니다." }`. 5번 틀리면 그 인증번호는 폐기합니다.

### PUT `/api/guardian/manage/{manage_token}/settings`

- 요청 `{ "feed_post": true }` 또는 `{ "dm_friends": false }` (보낸 키만 바꿈)
- 응답 `200 { "settings": { "feed_post": true, "dm_friends": false } }`
- `account_status`가 `suspended`면 `409`

### POST `/api/guardian/manage/{manage_token}/revoke`

- 동의 철회: 자녀 계정을 `suspended`로 바꾸고 로그인을 막습니다(403). 곡과 데이터는 지우지 않습니다.
- `guardian_consents.status`를 `revoked`로, `revoked_at` 기록.
- 응답 `200 { "message": "동의가 철회되었습니다. 자녀 계정 이용이 중지되었습니다." }`

### POST `/api/guardian/manage/{manage_token}/delete-request`

- 계정 삭제 요청을 접수합니다. 처리방침과 계정 삭제 안내 페이지의 "본인 확인 후 영업일 10일 이내" 기준에 맞춰 운영 대기열에 넣습니다.
- 응답 `200 { "message": "삭제 요청이 접수되었습니다. ..." }`

## 5. 심사용 테스트 계정

Google 심사자는 휴대폰 인증을 받을 수 없습니다. 어린이 테스트 계정(`playreview_child@lotusai.co.kr`)의 관리 레코드만 `otp_exempt = true`로 두고, 그 관리 링크를 Play Console 로그인 세부정보에 적습니다. 이 링크는 만료되지 않아야 합니다.

## 6. admin 페이지

- 어린이 계정 목록: 닉네임, 나이, 동의 상태, `feed_post`·`dm_friends` 값
- 관리 링크 문자 재발송 (보호자가 고객센터에 연락했을 때)
- 심사용 관리 링크 발급 (`otp_exempt`)
