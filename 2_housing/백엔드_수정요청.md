# 백엔드 수정 요청서

> 작성일: 2026-04-10
> 요청자: 프론트엔드 (모바일 앱)
> 긴급도: **높음** (현재 모바일에서 음악 재생 불가)

---

## 1. 문제 상황

모바일 앱에서 음악 재생 시 **403 Forbidden** 에러 발생

### 원인

`GET /api/tracks/stream/{track_id}` 응답:
```json
{
  "stream_url": "http://localhost:9100/music-platform-audio/tracks/...mp3?X-Amz-Signature=..."
}
```

- presigned URL의 호스트가 `localhost:9100`으로 생성됨
- 모바일 기기에서 `localhost`는 기기 자신을 가리키므로 접근 불가
- IP를 `192.168.219.106`으로 치환하면 MinIO presigned 서명이 깨져 403 발생
  (서명 시 `host` 헤더가 `localhost:9100`으로 포함되어 있기 때문)

---

## 2. 요청 사항 (택 1)

### 방법 A: 프록시 스트리밍 엔드포인트 추가 (권장)

`app/routes/tracks.py`에 아래 엔드포인트를 추가해주세요.
백엔드 서버가 MinIO에서 직접 오디오를 읽어 클라이언트에 전달하는 방식입니다.

```python
@router.get("/stream-proxy/{track_id}")
async def stream_track_proxy(track_id: str):
    """모바일 클라이언트용: MinIO 오디오를 직접 프록시 스트리밍"""
    from fastapi.responses import StreamingResponse

    if not ObjectId.is_valid(track_id):
        return JSONResponse(status_code=400, content={"error": "유효하지 않은 트랙 ID입니다."})

    mongo = get_mongo()
    doc = await mongo.tracks.find_one({"_id": ObjectId(track_id)}, {"audio_url": 1})
    if not doc or not doc.get("audio_url"):
        return JSONResponse(status_code=404, content={"error": "오디오 파일을 찾을 수 없습니다."})

    minio_client = get_minio()
    try:
        response = minio_client.get_object(
            bucket_name=settings.minio_bucket_music,
            object_name=doc["audio_url"],
        )
        content_type = "audio/mpeg"
        if doc["audio_url"].endswith(".wav"):
            content_type = "audio/wav"

        return StreamingResponse(
            response,
            media_type=content_type,
            headers={"Accept-Ranges": "bytes"},
        )
    except Exception:
        return JSONResponse(status_code=404, content={"error": "오디오 파일을 찾을 수 없습니다."})
```

모바일 앱에서 호출 방식:
```
GET http://192.168.219.106:9000/api/tracks/stream-proxy/{track_id}
```

### 방법 B: MinIO 외부 엔드포인트 설정 (대안)

MinIO 클라이언트 초기화 시 외부 IP를 사용하도록 변경:

`app/database/minio.py` 또는 `app/config.py`에서:
```python
# 현재: endpoint = "localhost:9100"
# 변경: endpoint = "192.168.219.106:9100"
```

이렇게 하면 presigned URL이 `http://192.168.219.106:9100/...`으로 생성되어
모바일에서 직접 접근 가능합니다.

**단, MinIO가 외부 접근을 허용해야 합니다** (`--address 0.0.0.0:9100`)

## 4. 적용 후 확인 방법

```bash
# 방법 A 적용 후 테스트
curl -o test.mp3 http://192.168.219.106:9000/api/tracks/stream-proxy/69ce5cd4874e73f0eb1b07af
# 파일이 정상적으로 다운로드되면 성공

# 방법 B 적용 후 테스트
curl -s http://192.168.219.106:9000/api/tracks/stream/69ce5cd4874e73f0eb1b07af
# stream_url이 192.168.219.106:9100 으로 시작하면 성공
```
