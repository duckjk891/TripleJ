## 1. 사용자가 설정할 수 있는 파라미터

### 사용 가능한 파라미터 (Suno)

| 파라미터 | UI 표기 | ON/OFF | 설명 |
|---------|---------|--------|------|
| 장르 | 장르 선택 | 항상 | K-Pop, Hip-hop 등 복수 선택 |
| 분위기 | 분위기 선택 | 항상 | Energetic, Chill 등 복수 선택 |
| 보컬 | 보컬 선택 | 항상 | 남성/여성 + 톤 (또는 Instrumental) |
| 스타일 설명 | 스타일 | 항상 | 자유 텍스트 |
| 참고 스타일 | 참고 스타일 | 항상 | 자유 텍스트 |
| 참고 음악 | 참고 음악 (선택사항) | 항상 | 오디오 파일 업로드 (최대 8분) |
| Negative Tags | 제외할 스타일 | 토글 | 생성에서 배제할 스타일 태그 |
| Style Weight | 스타일 가중치 | 토글 | 0.0~1.0 |
| Weirdness | 실험성 조절 | 토글 | 0.0~1.0 |
| Audio Weight | 오디오 영향도 | 토글 | 0.0~1.0 |
| BPM | BPM | 토글 | 숫자 입력 |
| Key | 키 | 토글 | C major, F minor 등 |
| Persona Model | 페르소나 타입 | 토글 | Style Persona / Voice Persona |

### 준비 중인 기능 (API 지원 대기)

| 기능 | 설명 | 상태 |
|------|------|------|
| 보이스 클로닝 | 내 목소리를 녹음/업로드하여 그 목소리로 노래 생성 | 🔒 비공식 API 지원 대기 중 |
| 커스텀 모델 학습 | 내 곡 6개 이상을 학습시켜 나만의 AI 모델 생성 (최대 3개) | 🔒 비공식 API 지원 대기 중 |
| My Taste | AI가 내 취향을 학습해서 점점 더 맞는 곡 생성 | 🔒 비공식 API 지원 대기 중 |
| MIDI 변환 | 생성된 오디오를 MIDI 파일로 변환하여 DAW에서 편집 | 🔒 비공식 API 지원 대기 중 |

## 2. 모든 파라미터 설정 시 프롬프트 미리보기 예시

```
K-Pop, 발라드 장르의 Romantic, Dreamy한 분위기로, 남성 - 따뜻한 보컬이 부르는 곡을 생성합니다.
템포는 120 BPM, 키는 C major입니다.
제외할 스타일로 heavy metal, screamo이(가) 지정되어 있습니다.
스타일 가중치는 0.7로 설정되어 있습니다.
창의성(Weirdness)은 0.3으로 설정되어 있습니다.
오디오 가중치는 0.5로 설정되어 있습니다.
페르소나 모델은 Style Persona로 설정되어 있습니다.
추가 스타일 설명으로 "부드러운 피아노 멜로디와 어쿠스틱 기타"이(가) 포함되어 있습니다.
참고할 스타일로 "2000년대 초반 R&B 발라드"이(가) 지정되어 있습니다.
업로드한 참고 음악(my_reference.mp3, 42초)의 스타일을 참고하여 생성합니다.
```

## 3. 프롬프트 템플릿

`StudioTab2.jsx`의 `buildPromptPreview()` 함수에서 사용하는 템플릿입니다.
설정하지 않은 파라미터는 해당 문장이 자동으로 생략됩니다.

### 1번 문장 (필수 — 장르 + 분위기 + 보컬 조합)

```
"{장르} 장르의 {분위기}한 분위기로, {보컬 라벨} 보컬이 부르는 곡을 생성합니다."
```

변형:
- 장르만: `"{장르} 장르의 곡을 생성합니다."`
- 분위기만: `"{분위기}한 분위기로, 곡을 생성합니다."`
- Instrumental: `"{장르} 장르의 {분위기}한 분위기로, 연주곡(Instrumental)을 생성합니다."`
- 아무것도 없으면: `"곡을 생성합니다."`

### 2번 문장 (BPM/Key — 있는 것만)

```
둘 다:  "템포는 {BPM} BPM, 키는 {Key}입니다."
BPM만:  "템포는 {BPM} BPM입니다."
Key만:  "키는 {Key}입니다."
```

### 3번~7번 문장 (Suno 고급 파라미터 — ON인 것만)

```
"제외할 스타일로 {negativeTagsVal}이(가) 지정되어 있습니다."
"스타일 가중치는 {styleWeightVal}로 설정되어 있습니다."
"창의성(Weirdness)은 {weirdnessVal}로 설정되어 있습니다."
"오디오 가중치는 {audioWeightVal}로 설정되어 있습니다."
"페르소나 모델은 {Style Persona | Voice Persona}로 설정되어 있습니다."
```

### 8번 문장 (스타일 설명 — 있으면만)

```
"추가 스타일 설명으로 \"{style}\"이(가) 포함되어 있습니다."
```

### 9번 문장 (참고 스타일 — 있으면만)

```
"참고할 스타일로 \"{referenceText}\"이(가) 지정되어 있습니다."
```

### 10번 문장 (참고 음악 — 업로드했으면만)

```
"업로드한 참고 음악({filename}, {duration_sec}초)의 스타일을 참고하여 생성합니다."
```
