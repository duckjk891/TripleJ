# 단계당 광고 1회 가정 비용 재계산 (v37)

작성일: 2026-04-24

## 전제

- 현재 UI는 **디렉터별 6단계 스테퍼**로 재설계됨
- **광고 1회 시청 = 1단계 스킵** 원칙 (MapScreen `showAdAndReduceQueue`가 `stageSize = initialQueue / 6`만큼 감소)
- 따라서 **광고 0회 자연대기** vs **광고 6회 전체 스킵** 두 극단 중에서 실제 사용자 분포를 예측해야 함
- 광고 단가: AdMob 보상형 전면 평균 **30~50원/회**(한국)

## 결론

**단계당 광고 1회(=총 6회) 단일 규칙으론 고가 모델에서 수지 안 맞음.**

## 해결 옵션

### A. 모델별 차등 단계 — "고가 모델은 단계당 N회 광고"
| 모델 | 단계당 광고 | 총 광고 | 광고 수익 | 수익 |
|------|------------|---------|-----------|------|
| GPT-4o Mini | 1회 | 6회 | 180~300 | +130~+250 |
| Claude Sonnet | 1회 | 6회 | 180~300 | -20~+100 |
| GPT-4o | 1~2회 | 6~12 | 180~600 | -120~+300 |
| GPT-4 Turbo | 2회 | 12회 | 360~600 | -140~+100 |
| Claude Opus | 5회 | 30회 | 900~1,500 | -600~0 |
| Suno | 3회 | 18회 | 540~900 | -460~-100 |
| MV | 10회 | 60회 | 1,800~3,000 | -1,200~0 |

- **장점**: 수치상 손익 맞춤
- **단점**: UX 저하 (Opus: 30회 광고, MV: 60회 → 비현실적)
- **현실성**: ⭐⭐

### B. 자연대기 유저 비율로 평균 보전 — "광고 볼 사용자만 고가 모델 유도"
- 광고 시청률 가정: Mini 80% / Opus 30% / Suno 20% / MV 10%
- 나머지 자연대기 유저는 원가만 소진 (광고 수익 0원)
- 결국 **자연대기 길이가 곧 비용 청구**인 구조
- 이 경우 **Suno 3~6시간은 의도적** — 대부분 포기하고 소모 감소

**평균 수익 예측 (사용자 100명당)**:
| 모델 | 광고 시청자 수익 | 자연대기 비용 | 순수익 |
|------|-------------------|---------------|--------|
| Mini (80% 광고) | 80×240 = 19,200 | 100×50 = 5,000 | **+14,200** |
| Opus (30% 광고) | 30×240 = 7,200 | 100×1,500 = 150,000 | **-142,800** |
| Suno (20% 광고) | 20×240 = 4,800 | 100×1,000 = 100,000 | **-95,200** |

**단점**: 고가 모델 여전히 손해. 시청률 더 높이거나 실제 호출 제한 필요.

### C. 프리미엄 결제 구독 유도 — "Pro 플랜으로 고가 모델 해금"
- Free: Mini / Claude Sonnet / Wondera / 이미지만 사용 가능
- Pro (월 9,900원): GPT-4o / GPT-4 Turbo / Claude Opus / Suno 해금 + 광고 제거
- MV는 별도 건당 결제

**추천 경로**: **B + C 혼합**
1. 단계당 광고 1회 유지 (UX)
2. Free 유저: Mini / Sonnet / Wondera 한정 (자체적으로 수지 맞음)
3. Pro 유료 유저: GPT-4o 이상 + Suno + MV 해금, 광고 면제
4. MV는 Pro 유저도 건당 별도 결제 (3,000원 이상)

## 현재 `timerStore.ts` 수치는 어떻게?

현재 설정 (`MODEL_QUEUE_CONFIG`):
- 대기번호 범위는 모델별 차등 (Mini 30~50, Opus 200~350, Suno 300~420)
- `stageSize = initialQueue / 6` 이므로 광고 1회 = 초기 큐의 1/6 감소

즉 **모델별로 한 단계 크기가 다름**. Opus는 한 단계가 33~58 감소, Mini는 5~9 감소.
광고 6회로 스킵하는 총량은 그 모델 고유의 initialQueue. **수치 구조는 적절**.
