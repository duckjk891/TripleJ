## 2. 분위기 / 무드

복수 선택 가능

- 밝고 경쾌한
- 슬프고 우울한
- 몽환적·신비로운
- 에너지틱·강렬한
- 로맨틱·달콤한
- 그리운·따뜻한
- 차갑고 쿨한
- 어둡고 무거운
- 잔잔하고 편안한
- 흥겹고 신나는

---

## 3. 주제 / 테마

복수 선택 가능

- 사랑
- 이별
- 짝사랑
- 우정
- 성장·자기계발
- 자유·일탈
- 희망·꿈
- 외로움·그리움
- 일상의 소소함
- 청춘·방황
- 사회비판
- 복수·분노

## 4. 화자 / 시점

단일 선택

- 1인칭 — 나
- 2인칭 — 너에게 말하는
- 3인칭 — 관찰자
- 독백체
- 대화체

---

## 5. 언어

단일 선택

- 한국어 100%
- 영어 조금 혼합 (20% 이하)
- 영어 많이 혼합 (절반 정도)
- 영어 100%

---

## 6. 가사 구조

단일 선택

- 절 — 후렴 (2절)
- 절 — 후렴 — 브릿지
- 절 — 후렴 (3절)
- 절 — 후렴 — 절 — 후렴 — 브릿지 — 후렴
- 자유 형식

---

## 7. 키워드 / 소재

복수 선택 + 직접 입력 가능

- 봄 / 여름 / 가을 / 겨울
- 바다
- 별·밤하늘
- 도시·야경
- 꿈
- 추억·기억
- 비·눈
- 카페·일상
- 여행·길
- 꽃
- 달·빛
- 직접 입력 (예: 노을, 첫사랑, 지하철)

---

## 8. 레퍼런스

자유 입력

참고하고 싶은 곡이나 아티스트를 입력합니다.

> 예시: IU - 밤편지 느낌, BTS Spring Day처럼, 장범준 스타일로
